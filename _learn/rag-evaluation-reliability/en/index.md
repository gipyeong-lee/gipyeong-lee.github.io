Create a fixed document set and question/answer evaluation set, then quantitatively measure retrieval quality, grounded faithfulness, citation accuracy, and failure modes to complete a reproducible RAG regression evaluation report.

Learners will be able to evaluate the retrieval and generation stages of a RAG pipeline separately and design a quantitative regression testing framework that utilizes automated evaluation tools like Ragas to reduce hallucinations and verify factuality.
