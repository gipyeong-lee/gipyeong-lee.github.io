### 로봇 시스템의 성능 평가 및 분석
로봇 시스템의 최종 성능 평가는 설계 단계에서 정의된 요구사항(Requirements)과 실제 구현된 시스템의 출력 간의 상관관계를 확인하는 필수 과정입니다 [S7]. 정교한 5지 로봇손의 경우, 액추에이터의 응답성, 센서의 정확도, 제어 시스템의 안정성이 성능을 결정하는 핵심 요소입니다 [S12, S13].

#### 1. 주요 성능 지표(KPI)
- **정밀도 및 정확도**: 관절 구동 명령과 실제 출력 각도의 오차를 분석하여 시스템의 정밀도를 정량화합니다.
- **동적 응답 특성**: 시스템이 단계적 입력(Step Input)에 대해 얼마나 신속하고 안정적으로 반응하는지(오버슈트 및 정착 시간)를 평가합니다.
- **파지력 피드백 성능**: `FSR 402` 센서를 통해 측정된 힘 데이터를 제어 알고리즘이 효과적으로 처리하여 파지력을 제어하고 있는지 분석합니다 [S13].
- **시스템 안정성**: 전력 분기 시스템(예: 3개의 `GST160A12-R7B` 어댑터 구성)의 부하 분산 상태와 비상 정지(EV200 접촉기) 작동의 신뢰성을 확인합니다 [S16, S23].

#### 2. 데이터 분석 방법론
실험 데이터는 시간 영역(Time Domain)에서의 변화를 그래프로 시각화하여 분석하며, 통계적 분석(평균, 표준편차)을 통해 반복 실험에 대한 시스템의 재현성을 검증합니다. 측정된 성능 지표가 시스템의 물리적 한계(예: 액추에이터 스톨 토크 4.1 N·m)를 초과하지 않는지 확인하는 것은 안전 및 신뢰성 측면에서 필수적입니다 [S12].
