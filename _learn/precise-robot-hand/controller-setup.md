## 제어기 설정 및 펌웨어 기초

### OpenCR 1.0 하드웨어 아키텍처
OpenCR 1.0은 216MHz 주파수의 CPU를 기반으로 하며 [S12], DYNAMIXEL 스마트 액추에이터와의 직접 통신을 위한 전용 포트를 내장하고 있습니다. 별도의 통신 브리지 없이 액추에이터 제어 명령을 처리하고 센서 피드백을 수집할 수 있어 복잡한 하드웨어 구성을 단순화합니다.

### 센서 데이터 취득: 전압 분압 회로
FSR 402 센서는 압력에 따라 저항이 변하는 가변 저항기입니다. 힘을 측정하기 위해 전압 분압 회로를 구성해야 합니다. OpenCR 1.0의 ADC 핀에 3.3V 센서 전원을 공급하고 FSR과 10kΩ 저항을 직렬로 연결합니다. 이 회로의 출력 전압은 다음 식을 따릅니다:

$$V_{out} = V_{in} \times \frac{R_{fixed}}{R_{FSR} + R_{fixed}}$$

여기서 $V_{in}$은 3.3V입니다. ADC 입력 신호가 0~3.3V 범위를 초과하지 않도록 회로를 반드시 3.3V 센서 전원 레일에서 구성하십시오.

### 안전 상태기계 (Safety State Machine)
로봇 시스템의 비정상 종료를 방지하기 위해 펌웨어 수준에서 안전 상태기계를 실행합니다. 정상 가동(RUN), 경고(WARN), 비상 정지(ESTOP) 상태로 구분하며, ESTOP 상태 진입 시 즉시 모든 액추에이터 토크를 비활성화하고 접촉기를 차단해야 합니다.
