### 로봇 펌웨어 제어 아키텍처
로봇 손의 제어는 고속 실시간성이 요구되는 액추에이터 제어와 입력 데이터 처리를 동시에 수행해야 합니다. 사용되는 `OpenCR 1.0` 제어기는 216MHz의 CPU 주파수를 지원하여 복잡한 상태기계와 통신 처리를 효율적으로 수행할 수 있습니다 [S13].

### 통신 및 액추에이터 제어
`XM430-W350-T` 액추에이터는 `DYNAMIXEL Protocol 2.0`을 기반으로 위치, 속도, 전류 피드백을 제공합니다 [S11]. 제어기는 별도의 브리지 회로 없이 내장된 DYNAMIXEL TTL/RS-485 포트를 통해 직접 명령을 전달하여 통신 안정성과 재현성을 확보합니다 [S13].

### 센서 데이터 처리 (FSR)
`FSR 402` 센서는 가해진 힘에 비례하여 저항이 감소하는 특성을 갖습니다 [S12]. 이를 전압 값으로 변환하기 위해 10kΩ 고정 저항과 전압 분압 회로를 구성합니다 [S25].
- **회로 구성:** 3.3V 센서 전원 → FSR → ADC 입력 핀 → 10kΩ 저항 → GND
교육용 프로토타입은 기계 안전 표준 준수나 인증을 주장하지 않으며, 사람 접근 환경 투입 전 자격 있는 안전 전문가의 별도 검토가 필요하다 [S13]. 12V 액추에이터 전원과 센서 회로를 물리적으로 엄격히 분리하십시오 [S13].
