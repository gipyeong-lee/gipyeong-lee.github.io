## 로봇 핸드 기구 설계 원리

로봇 핸드는 복잡한 물리적 환경에서 물체를 파지(grasping)하고 조작(manipulation)하는 말단 장치(end-effector)입니다. 설계의 핵심은 인간의 손이 가진 높은 자유도(DOF)와 기능성을 어떻게 적은 수의 액추에이터로 구현할 것인가에 있습니다 [S12, S13].

### 1. 언더액추에이션 (Underactuation)
로봇 핸드의 전체 관절 자유도보다 구동기(액추에이터)의 수가 적은 설계를 의미합니다 [S13, S14]. 이는 제어 시스템의 복잡성을 낮추고 비용을 절감하며, 대상 물체의 형상에 맞춰 손가락이 자연스럽게 휘어지는 적응형 파지(adaptive grasping)를 가능하게 합니다 [S12, S14].

### 2. 구동 메커니즘
주로 텐던(tendon, 와이어) 구동 방식이 널리 사용됩니다. 구동기에서 전달된 힘은 와이어를 통해 손가락 마디(phalanges)로 전달됩니다 [S12]. 인간의 근육 구조를 모사하여 주동근(agonist)과 길항근(antagonist) 쌍을 구현하면 더 정교한 동작 제어가 가능합니다 [S12, S15].

### 3. FDM 3D 프린팅 설계 고려사항
- **벽 두께**: 구조적 강성을 위해 최소 1.2mm 이상의 두께를 권장하며, 부하가 집중되는 부위는 보강 리브(rib)를 설계해야 합니다 [S73, S74].
- **오버행(Overhang)**: 서포트 최소화를 위해 45도 이상의 경사면은 챔퍼(chamfer)나 필렛(fillet)을 활용하여 설계합니다 [S74, S77].
- **공차(Clearance)**: 맞물리는 기구부 사이에는 최소 0.5mm 이상의 간극을 두어 출력 후 간섭을 방지해야 합니다 [S73, S77].
