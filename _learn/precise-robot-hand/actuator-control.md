## DYNAMIXEL 제어 아키텍처
5지 로봇손의 구동은 11개의 XM430-W350-T 스마트 액추에이터에 의해 이루어집니다 [S10]. 이 액추에이터는 위치, 속도, 그리고 전류 피드백을 실시간으로 제공하여 텐던 구동 시스템의 정밀한 장력 제어를 가능하게 합니다. 통신은 DYNAMIXEL Protocol 2.0을 사용하여 효율적인 데이터 패킷 전송을 수행합니다 [S10].

## 센서 인터페이스 설계
각 손끝에 내장된 FSR 402 센서는 0.2N에서 20N 범위의 접촉력을 감지합니다 [S11]. 이를 OpenCR 보드의 12비트 ADC로 읽기 위해 10kΩ 저항을 사용하는 전압 분압 회로를 구성합니다 [S12, S25].

### 안전 수칙: 전기 회로 구성
- 모든 FSR 분압 회로는 OpenCR의 3.3V 센서 전원 레일에 연결하십시오 [S12].
- 절대로 12V 액추에이터 전원 라인을 센서의 아날로그 분압 회로에 연결하지 마십시오. 이는 제어기를 영구적으로 손상시킵니다 [S12].
- 모든 아날로그 입력 신호는 0~3.3V 범위를 초과하지 않아야 합니다 [S12].

## 전원 배분 원칙
전체 시스템은 3개의 독립된 12V 전원 어댑터로 구동됩니다 [S14]. 각 어댑터는 4대, 4대, 3대의 액추에이터 분기로 분할되며, 각 분기는 10A ATOF 퓨즈로 개별 보호됩니다 [S14, S24]. 어댑터의 출력(+)단자를 서로 연결하는 행위는 엄격히 금지됩니다 [S14].
