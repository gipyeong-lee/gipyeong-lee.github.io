NIST 포스트퀀텀 표준의 수학적·보안적 가정을 이해하고, 고정된 로컬 테스트 시스템에서 암호자산을 식별·분류한 뒤 ML-KEM과 ML-DSA를 실험적으로 평가하여 우선순위 기반 전환 로드맵을 수립한다.
