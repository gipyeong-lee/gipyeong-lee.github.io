## Current Status and How It Works

So, how can Director's Lookbook actually be used, and what convenience features does it currently provide? River Road Labs, the developers, designed this tool in a fully open format to relieve the practical inconveniences experienced by creators.

1. **Completely Free Without Login**: There is no need to go through annoying membership registration or login procedures to use the service [[Show HN: Director's Lookbook, named looks for image, video and music prompts](https://directorslookbook.app/)]. You can freely receive style cards within your daily free allowance via the 'Feeling Reader' model that reads user emotions upon visiting the website [[Show HN: Director's Lookbook, named looks for image, video and music prompts](https://directorslookbook.app/)].
2. **Expansion to Various Media**: Going beyond mere photo prompts, it supports named looks across a wide range of domains including music videos, product photography, brand campaigns, game key art, and art-historical directing for images, videos, and music [[Director's Lookbook, the full reel: one style library for image, video...](https://www.youtube.com/watch?v=BQYSploxVPc)].
3. **MCP Server Support for Developers and Advanced Users**: One of the most innovative parts of this tool is that it supports a read-only Model Context Protocol (MCP, a standard communication specification helping AI models securely communicate with external data or tools) server [[Show HN: Director's Lookbook, named looks for image, video and music prompts](https://directorslookbook.app/)]. It operates immediately as a connector in AI development environments like Claude or Cursor without requiring authentication or separate API keys [[Show HN: Director's Lookbook, named looks for image, video and music prompts](https://directorslookbook.app/)].
4. **Rigorous Privacy Protection**: The MCP connector does not store any request text entered by users, recording only daily counts of how many times each tool was called per day [[Show HN: Director's Lookbook, named looks for image, video and music prompts](https://directorslookbook.app/)]. It provides a safe environment for creators who are deeply concerned about the security of their personal work.
