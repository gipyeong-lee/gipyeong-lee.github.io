### Assembly: The 'Magic Filter'

The term 'assembly language' might be unfamiliar. Let’s use an analogy to make it easier to understand.

Most programs we use are like cooking from a cookbook written in a language you don't speak fluently; they require a translation process for the machine to understand. In contrast, assembly language is the closest thing to 'machine code' that the computer hardware understands directly. It’s like handing ingredients directly to the chef (the computer) without going through a translator. [rhun — A small, fast code editor written in assembly | Launly](https://launly.com/products/rhun)

Because it’s built this way, Rhun is as light as a feather. Instead of carrying a heavy camera bag, it’s like heading out on a shoot with only the essential lens you need. As a result, memory usage is minimized, and the program startup speed is remarkably fast. [rhun: a small, fast code editor written in assembly](https://rhun.app/)
