試著想像一下：早上起床後，告訴機器人「請把今天成熟的草莓挑選出來並裝進籃子裡」，或者對工廠機器人下令「把這些伺服器零件組裝起來」。直到現在，要讓機器人學會這些任務，仍需要無數工程師、龐大的電腦設備以及數年的編碼工作。但現在，時代已經跨出一大步，我們可以像指揮 AI 繪圖一樣，更輕鬆、更聰明地訓練機器人。

近期，物理智慧 (Physical Intelligence, π) 公開了 API 測試版服務，讓機器人開發者可以直接運用他們最新的機器人學習模型 ([Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/))。這項為機器人學界開啟新大門的消息，將會帶來什麼樣的變革？為什麼它如此具有革命性？讓我們簡單來了解一下。

## 為什麼這很重要？

機器人最初是為了替代人類執行艱鉅或危險的工作而生。然而現實中，驅動機器人仍然背負著高昂成本與技術壁壘的巨大挑戰 ([Building safe physical AI: Open questions, risks, and... — EA Forum](https://forum.effectivealtruism.org/posts/EyNDeibxSymBWrRsr/building-safe-physical-ai-open-questions-risks-and-a-call))。

過去，機器人開發者為了讓單一機器人變得聰明，必須從零開始構建複雜的機器學習系統。這就像一個想學做菜的人，還得先買下一座農場並發明廚具一樣困難。此次公開的 API 測試版目標正是「機器人學習的普及化」。現在，機器人製造商可以在物理智慧已打下的堅實技術基礎上，更快速、更有效率地訓練自己的機器人 ([Physical Intelligence Opens API Beta for Its Robot Models](https://www.robotaigeek.com/news/physical-intelligence-opens-api-beta-for-robot-foundation-models/))。

## 簡單理解：機器人的「基礎教育」過程

物理智慧 (Physical Intelligence) 是一個致力於開發通用人工智慧模型的團隊，目標是讓任何機器人都能執行任何任務 ([PhysicalIntelligence(π)](https://www.pi.website/))。用簡單的比喻來說，他們正在為機器人打造共用的「大腦」。

透過這次公開的 API 測試服務，開發者可以使用兩大核心模型：「π0」與「π0.5」([Physical Intelligence opens Pi API beta for robot training ...](https://www.blackscarab.ai/news/physical-intelligence-pi-api-beta))。

運作方式主要分為三個階段：
1. **數據上傳**：就像孩子觀察父母的行為並模仿學習一樣，開發者將機器人執行特定任務所需的「行為數據」上傳到系統。
2. **微調 (Fine-tuning)**：在物理智慧已建立好的基礎學習模型 (π0, π0.5) 之上，開發者疊加自己上傳的數據，教導機器人掌握特定技術。
3. **雲端託管**：無需為每台機器人配備昂貴的運算設備。學習後的模型在雲端運作，機器人隨時都能呼叫使用 ([Physical Intelligence opens its π0 robot models to everyone via an API](https://robrief.com/en/companies/physical-intelligence))。

簡單來說，機器人已經領悟了基本的物理定律與動作基礎（相當於「小學教育」），之後只需透過 API 額外學習特定工作（相當於「專業教育」）即可。

## 現狀：進展到什麼程度了？

實驗已在多個領域展開。物理智慧透過這次公開，展示了無人輪式裝載機（重型設備）、採收草莓、伺服器組裝以及清除金屬零件毛邊等工作 ([Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/))。

這項技術的核心在於「通用性」。不僅是讓特定機器人表現優異，而是將同一個 AI 模型應用於不同型態的機器人上，都能協助它們自主判斷並動作 ([Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/))。不過，由於目前仍處於測試階段，並非所有開發者都能無限制使用，而是透過候補名單逐步開放存取權限 ([Physical Intelligence opens Pi API beta for robot training ...](https://www.blackscarab.ai/news/physical-intelligence-pi-api-beta))。

## 未來會如何發展？

我們現在看到了透過機器人克服勞動力短缺難題的可能性 ([Building safe physical AI: Open questions, risks, and... — EA Forum](https://forum.effectivealtruism.org/posts/EyNDeibxSymBWrRsr/building-safe-physical-ai-open-questions-risks-and-a-call))。未來，我們不再需要親手輸入數千行程式碼來訓練機器人，僅憑藉著指揮機器人工作的「數據」，就足以讓它們勝任專業任務。不久之後，我們將會習以為常地看到機器人採收餐桌上的草莓，甚至親自組裝我們使用的電腦伺服器。
