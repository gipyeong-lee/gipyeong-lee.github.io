<h4>
? 使用方法说明
</h4>
<ol>
<li>
<b>
绿肥作物：
</b>
?
<ul>
<li>
<b>
方法：
</b>
在作物周围种植绿肥作物，生长后将其翻入土中并混合。以此为土壤供应有机物和营养成分。
</li>
</ul>
</li>
<li>
<b>
有机物：
</b>
♻️
<ul>
<li>
<b>
方法：
</b>
将堆肥、厨余垃圾或植物残渣混入作物周围土壤，以提高土壤肥力。
</li>
</ul>
</li>
<li>
<b>
草木灰：
</b>
?
<ul>
<li>
<b>
方法：
</b>
将碱性的草木灰少量撒在作物周围土壤上，用以调节酸碱度并补充所需的微量元素。
</li>
</ul>
</li>
<li>
<b>
骨粉：
</b>
?
<ul>
<li>
<b>
方法：
</b>
将磨碎的动物骨头制成的骨粉混入作物周围土壤，以补充磷元素。
</li>
</ul>
</li>
<li>
<b>
海藻：
</b>
?
<ul>
<li>
<b>
方法：
</b>
将海藻堆肥后混入作物周围土壤，以提供磷和多种营养成分。
</li>
</ul>
</li>
<li>
<b>
磷矿粉：
</b>
?
<ul>
<li>
<b>
方法：
</b>
将天然磷矿粉混入作物周围土壤，使磷缓慢释放。
</li>
</ul>
</li>
<li>
<b>
香蕉皮：
</b>
?
<ul>
<li>
<b>
方法：
</b>
将香蕉皮干燥后制成粉末，混入作物周围土壤以补充钾元素。
</li>
</ul>
</li>
<li>
<b>
蛋壳：
</b>
?
<ul>
<li>
<b>
方法：
</b>
将蛋壳干燥后制成粉末，混入作物周围土壤以补充钙元素。
</li>
</ul>
</li>
<li>
<b>
灌溉管理：
</b>
?
<ul>
<li>
<b>
方法：
</b>
通过适量浇水来管理土壤电导率，以防止盐分积累。
</li>
</ul>
</li>
</ol>
