<h4>
? 사용 방법 설명
</h4>
<ol>
<li>
<b>
녹비 작물:
</b>
?
<ul>
<li>
<b>
방법:
</b>
작물 주변에 녹비 작물을 심고, 자라난 후 이를 갈아엎어 토양에 혼합합니다. 이를 통해 유기물과 영양소를 토양에 공급합니다.
</li>
</ul>
</li>
<li>
<b>
유기물:
</b>
♻️
<ul>
<li>
<b>
방법:
</b>
퇴비나 음식물 쓰레기, 식물성 잔재물을 작물 주변의 흙에 섞어 토양의 비옥도를 높입니다.
</li>
</ul>
</li>
<li>
<b>
목재 재:
</b>
?
<ul>
<li>
<b>
방법:
</b>
알칼리성 목재 재를 소량 작물 주변의 흙에 뿌려서 산도를 조절하고 필요한 미량 영양소를 보충합니다.
</li>
</ul>
</li>
<li>
<b>
뼛가루:
</b>
?
<ul>
<li>
<b>
방법:
</b>
동물의 뼈를 분쇄하여 만든 뼛가루를 작물 주변 흙에 섞어 인산을 보충합니다.
</li>
</ul>
</li>
<li>
<b>
해조류:
</b>
?
<ul>
<li>
<b>
방법:
</b>
해조류를 퇴비화하여 작물 주변 흙에 섞어 인산과 다양한 영양소를 공급합니다.
</li>
</ul>
</li>
<li>
<b>
바위 인산염:
</b>
?
<ul>
<li>
<b>
방법:
</b>
자연 인산염 광물을 작물 주변 흙에 혼합하여 인산을 서서히 방출시킵니다.
</li>
</ul>
</li>
<li>
<b>
바나나 껍질:
</b>
?
<ul>
<li>
<b>
방법:
</b>
바나나 껍질을 건조시켜 분말로 만든 후 작물 주변 흙에 섞어 칼륨을 보충합니다.
</li>
</ul>
</li>
<li>
<b>
계란 껍질:
</b>
?
<ul>
<li>
<b>
방법:
</b>
계란 껍질을 건조시켜 분말로 만든 후 작물 주변 흙에 섞어 칼슘을 보충합니다.
</li>
</ul>
</li>
<li>
<b>
관개 관리:
</b>
?
<ul>
<li>
<b>
방법:
</b>
염류 축적을 방지하기 위해 적절한 양의 물을 주어 토양의 전기전도도를 관리합니다.
</li>
</ul>
</li>
</ol>
