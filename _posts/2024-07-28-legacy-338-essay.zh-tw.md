<p>
大家好？？
<br>
我是 &lt;별앗간농부들&gt;（星芽農人）的「露地草莓」。？
<br>
今天我要介紹如何在溫暖潮濕的島嶼地區輕鬆製作海藻基堆肥。這個方法對生態農業很有幫助，而且容易上手。我也會說明針對不同氣候的管理方法，請找出適合您農場的方式吧！？
</p>
</blockquote>
<h4>
溫暖潮濕島嶼地區的特徵
</h4>
<ul>
<li>
<b>
溫度：
</b>
氣溫溫暖且波動小。
</li>
<li>
<b>
濕度：
</b>
高濕度持續，土壤和空氣始終處於潮濕狀態。
</li>
<li>
<b>
降雨量：
</b>
經常下雨，降雨量多。
</li>
</ul>
<h2>
? 各氣候的海藻基堆肥管理方法
</h2>
<h3>
1. 溫暖潮濕氣候
</h3>
<p>
<b>
特徵：
</b>
持續溫暖與高濕度的氣候
</p>
<p>
<b>
管理方法：
</b>
</p>
<ul>
<li>
<b>
排水管理：
</b>
由於高濕度，必須妥善管理排水，以防堆肥堆過於潮濕。堆積堆肥時，請選擇排水良好的地點，並在底部鋪設小石頭或樹枝等建立排水層。
</li>
<li>
<b>
通風：
</b>
高濕度容易導致堆肥腐爛，因此需定期翻堆以利通風。請使用耙子或鏟子，每兩週翻動一次。
</li>
<li>
<b>
覆蓋：
</b>
用布或塑膠布覆蓋堆肥堆以防雨淋。若降雨量大，此舉可防止堆肥過度潮濕。
</li>
<li>
<b>
溫度監控：
</b>
在溫暖氣候下，堆肥發酵可能進行得很快，請定期監控發酵溫度。堆肥溫度若過高可能會導致腐敗。
</li>
</ul>
<h3>
2. 乾燥氣候
</h3>
<p>
<b>
特徵：
</b>
低濕度與高氣溫
</p>
<p>
<b>
管理方法：
</b>
</p>
<ul>
<li>
<b>
保持水分：
</b>
定期灑水，以防堆肥堆過於乾燥。請確保堆肥堆始終保持濕潤狀態。
</li>
<li>
<b>
遮陽：
</b>
為保護堆肥免受強烈陽光曝曬，請將堆肥堆設在陰涼處，或使用遮陽網覆蓋。
</li>
<li>
<b>
分層堆疊：
</b>
堆積堆肥時，將海藻與其他有機物交替分層堆疊，有助於均勻保持水分。
</li>
</ul>
<h3>
3. 寒冷氣候
</h3>
<p>
<b>
特徵：
</b>
低氣溫與高濕度
</p>
<p>
<b>
管理方法：
</b>
</p>
<ul>
<li>
<b>
保溫：
</b>
注意保溫以防堆肥堆結凍。堆疊堆肥時請堆得厚實些，以維持內部溫度。
</li>
<li>
<b>
覆蓋：
</b>
用布或塑膠布覆蓋堆肥堆以保存熱量，並防護積雪或雨水。
</li>
<li>
<b>
促進發酵：
</b>
低氣溫下發酵較慢，為促進發酵，請定期翻堆以供應空氣。
</li>
</ul>
<h2>
? 製作海藻基堆肥：簡單易學的方法
</h2>
<h3>
準備物品
</h3>
<ul>
<li>
海藻（新鮮或乾燥皆可）
</li>
<li>
耙子或鏟子
</li>
<li>
可製作堆肥堆的空間（戶外）
</li>
<li>
其他有機物（例如：割下的草、落葉、廚餘）
</li>
<li>
水
</li>
</ul>
<h3>
? 海藻基堆肥製作步驟指南
</h3>
<p>
<b>
1. 收集海藻（第 1 天）
</b>
</p>
<ul>
<li>
<b>
地點：
</b>
從海邊收集海藻。海藻通常在退潮時會大量堆積在海灘，請先確認潮汐時間再進行收集。
</li>
<li>
<b>
種類：
</b>
褐藻類、紅藻類等各種海藻皆可使用。
</li>
</ul>
<p>
<b>
2. 清洗海藻（第 1 天）
</b>
</p>
<ul>
<li>
<b>
方法：
</b>
用清水徹底清洗收集到的海藻，去除鹽分、沙子及雜質。若殘留過多鹽分會對土壤造成負面影響，請務必徹底清洗。
</li>
</ul>
<p>
<b>
3. 乾燥海藻（1~3 天）
</b>
</p>
<ul>
<li>
<b>
方法：
</b>
將清洗過的海藻鋪在陽光充足處乾燥。不一定要完全乾燥，但若水分過多，可能會減緩堆肥化過程。
</li>
<li>
<b>
期間：
</b>
根據天氣和海藻種類而定，通常需要 1~3 天。
</li>
</ul>
<p>
<b>
4. 建立堆肥堆（第 1 天）
</b>
</p>
<ul>
<li>
<b>
建立基底：
</b>
決定堆肥的地點，並用耙子或鏟子整理地面。
</li>
<li>
<b>
堆疊分層：
</b>
將海藻與其他有機物分層堆疊。例如：海藻層 15cm、割下的草 15cm、落葉 15cm、廚餘 15cm，以此類推重複堆疊。
</li>
<li>
<b>
灑水：
</b>
堆疊每一層時適量灑水。只需保持堆肥堆濕潤即可，注意不要澆過多的水。
</li>
</ul>
<p>
<b>
5. 翻動堆肥（1~3 個月）
</b>
</p>
<ul>
<li>
<b>
首次翻堆（2 週後）：
</b>
建立堆肥堆約 2 週後進行第一次翻堆。使用耙子或鏟子翻動堆肥堆以供應空氣。
</li>
<li>
<b>
定期翻堆（每 2~3 週）：
</b>
之後每 2~3 週翻動一次堆肥。此過程可促進堆肥分解，並透過供應空氣使發酵過程順利進行。
</li>
<li>
<b>
期間：
</b>
堆肥完全發酵大約需要 1~3 個月。發酵期間會依季節、氣候及所使用的材料而有所不同。
</li>
</ul>
<p>
<b>
6. 堆肥完成與使用（3 個月後）
</b>
</p>
<ul>
<li>
<b>
檢查完成：
</b>
當堆肥呈現深褐色，且質感柔軟、像泥土一樣時，即表示準備就緒。味道也應該聞起來有泥土的芳香。
</li>
<li>
<b>
使用方法：
</b>
將完成的堆肥撒在作物根部周圍，或在種植前與土壤充分混合。
</li>
</ul>
<h2>
? 注意事項
</h2>
<ul>
<li>
<b>
去除鹽分：
</b>
必須徹底清洗海藻以去除鹽分。
</li>
<li>
<b>
水分控制：
</b>
適度控制水分，防止堆肥堆過於潮濕。
</li>
<li>
<b>
通風：
</b>
定期翻動堆肥堆以供應空氣。
</li>
</ul>
