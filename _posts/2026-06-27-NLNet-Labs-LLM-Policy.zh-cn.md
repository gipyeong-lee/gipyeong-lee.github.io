想象一下，你每天使用的自来水管实际上是由机器人设计的，但那个机器人有时会做出错误的决定，导致水流中断，那会怎样？在我们肉眼看不见的互联网世界里，也有着扮演这种“水管”角色的技术。我们将访问的网站地址转换为数字的DNS（域名系统，起着互联网地址簿的作用）就是其中之一。然而，在这个构建重要基础设施的社区中，最近做出了一项有趣且坚决的决定。

研究和开发互联网基础设施基石的非营利组织NLnet Labs于2026年6月26日发布了一项关于AI使用的新政策。[NLnetLabsrestrictsLLM-generated code and docs | LavX News](https://news.lavx.hu/article/nlnet-labs-restricts-llm-generated-code-and-docs) 其核心非常明确，即“必须由人亲自编写”。

### 为什么这很重要？

在日常生活中，看到AI撰写的电子邮件或报告已是常事，但在处理互联网心脏地带的地方，情况则完全不同。这项政策不仅仅是一条简单的规则，它还提出了一个沉重的话题：**“互联网基础设施的信任”**在多大程度上应由人类负责。[NLnetLabs| lobbyfacts](https://www.lobbyfacts.eu/datacard/nlnet-labs?rid=604493250015-26) 

对于普通用户来说，这并不意味着互联网会立即变慢，但这是一个重要的案例，展示了开源（任何人都可以查看和修改代码的软件）生态系统如何在AI的巨大影响下试图保持其身份。因为代码不仅是简单的指令，更是包含某人深思熟虑的精密蓝图。

### 浅显易懂：确认“基本功”的过程

让我们这样比喻：当厨师为客人准备食物时，食谱是由AI制定的还是人亲自构思的，在味道上可能没有太大区别。但如果餐厅的卫生管理或证明食材产地的“记录本”是由别人代写的呢？如果出现问题时，回答“因为记录是机器人写的，所以不太清楚”，客人们会感到非常不安。

NLnet Labs的此次决定也与之类似。因为与写出“好”代码一样，**“谁负责编写的”**在基础设施安全方面才是关键。[NLnet Labs restricts LLM-generated contributions to projects](https://letsdatascience.com/news/nlnet-labs-restricts-llm-generated-contributions-to-projects-0897df70) 

如果说现有的开源协作是基于“共同创作的同事”之间的信任，那么AI的出现则使该信任对象变得模糊。今后，贡献者在报告错误或提交代码时，必须透明地公开是否使用了AI（通过学习海量数据来生成句子的AI，即大语言模型）。[NLnet Labs restricts LLM-generated contributions to projects](https://letsdatascience.com/news/nlnet-labs-restricts-llm-generated-contributions-to-projects-0897df70)

### 限制到什么程度？

目前，NLnet Labs要求所有代码、文档甚至项目评论都由人类直接撰写。[NLnetLabsrestrictsLLM-generated code and docs | LavX News](https://news.lavx.hu/article/nlnet-labs-restricts-llm-generated-code-and-docs) 换句话说，这表明了即使是机器打草稿、人稍微修改一下的程度，在政策上也是拒绝的强烈意志。

当然，这并不是无条件排斥AI。核心在于，如果使用了，就不要隐藏，要诚实地说明。[NLnet Labs restricts LLM-generated contributions to projects](https://letsdatascience.com/news/nlnet-labs-restricts-llm-generated-contributions-to-projects-0897df70) 这应被理解为一种重新确认对技术产物“人类责任感”的措施，而非否定AI技术本身的效率。

### 未来会怎样？

未来，其他开源项目也很有可能陆续引入这种“AI作者验证”政策。因为对于稳定性高于一切的领域（如互联网基础设施）来说，追踪和验证代码是如何生成的变得愈发重要。[NLnet;NLnetLabs](https://nlnet.nl/project/nlnetlabs/) 各位读者今后在接触开源软件时，关注“这段代码是否由人类直接管理？”也将变得更加重要。

这正是我们关注这些试图安全管理互联网这条巨大水管的人们，他们的努力将如何在AI时代进化的原因。
