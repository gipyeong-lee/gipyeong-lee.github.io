<h2>
2. ビジョンと目標
</h2>
<ol>
<li>
<strong>
基礎への投資
</strong>
— 構造・断熱・防水は後からの施工が困難なため最優先。
</li>
<li>
<strong>
維持費の削減
</strong>
— 高効率の窓・設備、自然採光・通風の最大化。
</li>
<li>
<strong>
DIYの完結性
</strong>
— 作業ステップを細分化し、週末や夜間の作業でも進行可能な設計。
</li>
</ol>
<blockquote>
<p>
<span>
<p>
<strong>
Must‑Know
</strong>

<em>
Need / Want
</em>
の区別を通じて、意思決定の基準を確立する。
</p>
</span>
</p>

<h2>
3. 現況評価
</h2>
<h3>
3.1 屋根（瓦・屋上防水）
</h3>
<ul>
<li>
瓦下部の防水シートの状態確認 → 損傷部位を特定。
</li>
<li>
屋上のウレタン／ポリウレアコーティングが必要な面積を算出。
</li>
</ul>
<h3>
3.2 外壁
</h3>
<ul>
<li>
サーモグラフィー（レンタル）で結露・漏水箇所を検知。
</li>
<li>
断熱材の厚み／既存仕上げ層の厚みを記録。
</li>
</ul>
<h3>
3.3 内部
</h3>
<ul>
<li>
電気配線 — 露出や被覆のひび割れをチェック。
</li>
<li>
給排水 — メイン配管の口径、逆流の痕跡を記録。
</li>
</ul>
<p>
写真・寸法・メモを
<strong>
Google Drive › Renovation › Survey
</strong>
フォルダに保存する。
</p>
<hr>
<h2>
4. 法的・構造的制約
</h2>
<ol>
<li>
<strong>
用途地域／建ぺい率
</strong>
: 区役所建築課で書類を閲覧。
</li>
<li>
<strong>
耐力壁の識別
</strong>
: 木造トラス・梁の位置を表示。
</li>
<li>
<strong>
屋上防水の許認可
</strong>
: 防水層性能証明書を保管（瑕疵保険用）。
</li>
</ol>
