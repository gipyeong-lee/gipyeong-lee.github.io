想像一下。您為了尋找最愛的料理食譜而打開網路。和平常一樣，您點擊了 Google Chrome 或其他您慣用的瀏覽器，結果電腦卻突然跳出來說：「這道料理用這款瀏覽器看才最美味」，並強行開啟了另一個瀏覽器。忍耐一兩次或許還行，但如果每次都發生這種事呢？

不幸的是，這正是許多 Windows 使用者現在所遭遇的不便。100 天前，開發 Firefox 瀏覽器的 Mozilla 曾發布報告，指出了微軟這種「強推 Edge」的策略，但遺憾的是，情況並未發生顯著改善。甚至有評論指出，手段反而變得更加巧妙了。

### 這為什麼重要？

網頁瀏覽器就像是我們進入網路世界的「玄關」。它負責管理密碼、維護個人瀏覽紀錄，並打造符合個人喜好的網頁環境。因此，使用哪個玄關完全是使用者的權利。

然而，微軟正利用 Windows 作業系統和生成式 AI「Copilot」，為使用者「帶路」，引導他們自然而然地使用 Edge。這不僅僅是提高瀏覽器市佔率的問題，由於科技巨頭能夠操縱使用者的自主選擇權，這被視為一個嚴重的問題。瀏覽器選擇聯盟（Browser Choice Alliance）批評這種行為限制了使用者掌控自己環境的能力 [出處：Dark patterns in Windows are steering users to Edge: Mozilla ...](https://www.theregister.com/os-platforms/2026/07/15/dark-patterns-in-windows-are-steering-users-to-edge-mozilla-commissioned-report/5271792)。

### 淺顯易懂：已經安排好的餐廳動線

簡單來說，微軟的策略就像是「引導客人到餐廳角落座位的老闆」的手法。

原本客人應該要能坐在自己想要的座位上。但餐廳老闆從入口處就設置了複雜的障礙，讓客人無法前往想要的方位，並僅將通往特定角落座位（Edge）的燈光照得通明。

進入 Windows 11 後，微軟進一步加強了這種設計上的小動作。尤其是 AI 助手「Copilot」。當使用者與 Copilot 對話並點擊網頁連結時，Copilot 會忽略使用者預先設定好的預設瀏覽器，直接在自己的「側邊面板」中開啟網頁 [出處：Mozilla saysMicrosoftstillsteersWindowsuserstowardsEdge...](https://www.hindustantimes.com/business/mozilla-says-microsoft-still-steers-windows-users-towards-edge-except-in-the-eu-101791367540045.html)。等於是說，我們必須在微軟指定的空間而非自己選擇的瀏覽器中查看資訊。

### 我們站在哪裡？

在當前的數位環境中，使用者的權利正逐漸被企業的演算法所侵蝕。許多使用者為了方便而使用 Copilot 或 Windows 的推薦功能，但代價卻是付出了「選擇的自由」。我們必須以批判的眼光審視這些常用的技術工具，究竟是真心為使用者著想，還是充當了將使用者困在企業自家服務中的「圍欄」。

### 100 天後的成績單：更加巧妙的引導

根據 Mozilla 進行的調查，儘管 100 天前透過《Over the Edge 2.0》報告讓這種作法首次公諸於世，但微軟完全沒有改進 [出處：100 Days Later: Microsoft still undermines browser choice](https://daily.dev/posts/100-days-later-microsoft-still-undermines-browser-choice-b7schgjmq)。

此外，最新的調查結果顯示，進入 2026 年後情況反而變本加厲。以轉換至 Windows 11 或 Copilot 等新功能為名，將使用者引導至 Edge 的企圖，使用了比以往更具攻擊性的設計模式 [出處：100DaysLater:Microsoftstillundermines browser choice](https://blog.mozilla.org/en/mozilla/over-the-edge-2-100-days-later/)。除了擁有嚴格法律監管的歐洲之外，全球許多地區的 Windows 使用者依然暴露在這種強制引導的環境中 [出處：Tux Machines — Web Browsers: Opera, Chrome, and Mozilla](https://news.tuxmachines.org/n/2026/10/08/Web-Browsers-Opera-Chrome-and-Mozilla.shtml)。

### 未來會如何？

如果技術的發展不是為了幫助人類，而是為了「操縱」使用者去使用企業的特定產品，這是一個非常危險的訊號。Mozilla 的報告警告，微軟仍然持續利用 Windows、Copilot 和 Bing 搜尋服務的連動，運用「設計上的小動作」來引導使用者至 Edge [出處：Microsoft Persists in Undermining Browser Choice in Windows ...](https://o-server.main.jp/hacker-news/en/articles/2026/10/07/microsoft-persists-in-undermining-browser-choice-in-windows-mozil-50000431.html)。

消費者未來需要變得更加敏銳。如果在操作電腦時，總是跳出不想要的瀏覽器，或是感覺到選擇權被巧妙地剝奪，這絕非偶然。為了對企業的這種策略敲響警鐘，使用者主動找回自己的瀏覽器設定權，並持續為企業的壟斷行為發聲，至關重要。

當我們選擇的瀏覽器成為我們觀看網路世界的真正窗口時，健康的數位環境才算真正開始。
