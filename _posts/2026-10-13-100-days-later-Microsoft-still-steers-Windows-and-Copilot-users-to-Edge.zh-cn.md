想象一下：你打开互联网是为了查找一份心仪的菜谱。当你点击平时常用的 Google Chrome 或其他浏览器时，电脑却突然弹窗说“这道菜用这个浏览器看最有味道”，并强制打开了另一个浏览器。忍一两次或许没问题，但如果这种情况反复发生，你会作何感想？

不幸的是，这正是许多 Windows 用户目前面临的困扰。100 天前，火狐浏览器 (Firefox) 的开发商 Mozilla 发布了一份报告，指出了微软这种“强推 Edge”的策略，但遗憾的是，情况并无显著改善。甚至有人评价称，微软的手段变得更加狡猾了。

### 这为什么重要？

网页浏览器就像是我们连接互联网世界的“大门”。在这里管理密码、保存浏览记录，并打造符合个人喜好的网络环境。因此，使用哪扇大门，完全是用户的权利。

然而，微软正利用 Windows 操作系统和生成式 AI“Copilot”，引导用户“自然而然”地转向使用 Edge。这不仅是提高浏览器市场份额的问题，更因科技巨头能够操控用户的自主选择权而引发了严重关切。浏览器选择联盟 (Browser Choice Alliance) 批评称，这种行为限制了用户对自己电脑环境的把控能力 [出处: Dark patterns in Windows are steering users to Edge: Mozilla ...](https://www.theregister.com/os-platforms/2026/07/15/dark-patterns-in-windows-are-steering-users-to-edge-mozilla-commissioned-report/5271792)。

### 通俗理解：餐厅里“预设的动线”

简单来说，微软的策略类似于“引导客人坐到餐厅角落位置的经理”手段。

本应由客人自由选择座位，但餐厅老板在入口处设置了复杂的障碍，让人无法顺心如意地走，并且只给通往特定角落位置（Edge）的路铺设了明亮的灯光。

随着 Windows 11 的普及，微软进一步强化了这种设计手段，AI 助手“Copilot”便是典型代表。当用户与 Copilot 对话并点击网页链接时，Copilot 会直接忽略用户预设的默认浏览器，转而在自己的“侧边栏”中打开页面 [出处: Mozilla saysMicrosoftstillsteersWindowsuserstowardsEdge...](https://www.hindustantimes.com/business/mozilla-says-microsoft-still-steers-windows-users-towards-edge-except-in-the-eu-101791367540045.html)。也就是说，用户无法在自己选择的浏览器中查看信息，只能在微软指定的空间里观看。

### 我们处于什么立场？

在当前的数字环境中，用户的权利正逐渐被企业的算法所蚕食。许多用户为了便利而使用 Copilot 或 Windows 的推荐功能，但代价却是失去了“选择的自由”。我们需要批判性地审视这些常用的技术工具：它们究竟是在真正为用户服务，还是在扮演着将人囚禁在企业自有服务生态中的“围墙”？

### 100 天后的成绩单：更加狡猾的诱导

根据 Mozilla 的调查，尽管 100 天前通过《Over the Edge 2.0》报告使这种做法公之于众，但微软并未做出任何改善 [出处: 100 Days Later: Microsoft still undermines browser choice](https://daily.dev/posts/100-days-later-microsoft-still-undermines-browser-choice-b7schgjmq)。

此外，最新的调查结果显示，进入 2026 年，情况反而变得更糟。无论是在升级 Windows 11 的过程中，还是打着 Copilot 等新功能的旗号，将用户拉向 Edge 的尝试比以往使用了更具攻击性的设计模式 [出处: 100DaysLater:Microsoftstillundermines browser choice](https://blog.mozilla.org/en/mozilla/over-the-edge-2-100-days-later/)。除了法律监管严格的欧洲地区外，全球许多地方的 Windows 用户依然暴露在这种强制引导的环境中 [出处: Tux Machines — Web Browsers: Opera, Chrome, and Mozilla](https://news.tuxmachines.org/n/2026/10/08/Web-Browsers-Opera-Chrome-and-Mozilla.shtml)。

### 未来将会怎样？

如果技术的发展不是为了帮助人类，而是为了“操纵”人类去使用企业的特定产品，这将是一个极其危险的信号。Mozilla 的报告警告称，微软依然在联动 Windows、Copilot 和 Bing 搜索服务，不断利用“设计上的手段”将用户引导至 Edge [出处: Microsoft Persists in Undermining Browser Choice in Windows ...](https://o-server.main.jp/hacker-news/en/articles/2026/10/07/microsoft-persists-in-undermining-browser-choice-in-windows-mozil-50000431.html)。

消费者需要变得更加敏锐。在使用电脑时，如果反复出现不想要的浏览器，或者感觉到选择权在被狡猾地剥夺，那绝非偶然。为了给企业的这种策略敲响警钟，用户积极维护自己的浏览器设置权限，并持续对企业的垄断行为发出声音，显得尤为重要。

只有当我们选择的浏览器成为我们观察互联网世界的真正窗口时，健康的数字环境才会随之开启。

技术应为我们的便利而存在，不应为了企业的份额之争而限制用户的选择。我们今天所经历的不便，终将成为夺回数字主权的转折点。
