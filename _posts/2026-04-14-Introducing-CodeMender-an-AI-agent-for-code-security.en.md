# The Rise of the AI Sheriff: Introducing 'CodeMender,' the AI Agent for Code Security by Google DeepMind

Imagine you are building a 4.5-million-story skyscraper. This building contains hundreds of millions of bricks and tens of thousands of doors and windows. Then, one day, someone discovers a tiny gap somewhere in this massive structure where a thief could sneak in.

For a human to walk through every room and hallway of this vast building to find that needle-in-a-haystack gap might take years, if not decades. But what if there was a smart robot sheriff who could scan the entire building in an instant—as if with X-ray vision—not only find the gap but immediately fill it with cement and even say, "I'll redesign the wall structure itself to be stronger so this kind of gap never happens again"?

This kind of innovation is actually happening in the world of the smartphone apps and computer programs we use every day. Google DeepMind recently unveiled **CodeMender**, a new AI agent that can autonomously find and fix security vulnerabilities (weaknesses in programs that hackers can exploit) [Introducing CodeMender: an AI agent for code security](https://deepmind.google/blog/introducing-codemender-an-ai-agent-for-code-security/).

Today, we’ll take a closer look at the work of this 'smart code repairman' that is keeping our digital world safer from behind the scenes.

## Why is this important?

All the software we use is made up of code (sets of instructions given to a computer) written by humans. However, because humans do the work, even veteran developers make mistakes, and these small errors become critical 'security holes' that hackers can exploit.

Until now, expert security technicians have examined code one by one, as if using a magnifying glass, to find these holes. But the scale of software has now far exceeded human limits. For example, some modern programs contain as many as 4.5 million lines of code [Meet CodeMender: The Next Frontier in AI-Driven Code Security](https://tech-now.io/en/blogs/meet-codemender-the-next-frontier-in-ai-driven-code-security). If you printed 4.5 million lines on paper and stacked them up, it would be a massive amount reaching all the way to the stratosphere.

CodeMender minimizes the threat of cyberattacks by automatically detecting and diagnosing security flaws in this vast sea of code and even providing real-time repair patches (pieces of code added to fix errors) [Google DeepMind's CodeMender arrives: AI agent guarantees unbreakable code security and real-time bug fixes](https://economictimes.indiatimes.com/ai/ai-insights/google-deepminds-codemender-arrives-ai-agent-guarantees-unbreakable-code-security-and-real-time-bug-fixes/articleshow/124597476.cms). Evan Kotsovinos of Google DeepMind emphasized this as an effort to "secure the new frontiers of AI" [Google DeepMind unveils CodeMender, an AI-powered code security...](https://news.google.com/stories/CAAqNggKIjBDQklTSGpvSmMzUnZjbmt0TXpZd1NoRUtEd2lwaTh6Y0R4RS15U1IyWlBOX2VTZ0FQAQ?hl=en-IN&gl=IN&ceid=IN:en).

## Easy understanding: How does CodeMender work?

The way CodeMender works isn't just a simple game of "spot the difference." This AI possesses incredible reasoning abilities that allow it to understand complex contexts and think deeply.

### 1. It has a genius brain called 'Gemini Deep Think'
CodeMender utilizes **'Gemini Deep Think'**, the most advanced reasoning capability among Google's latest Gemini AI models [Introducing CodeMender: AI agent for code security flaws | LinkedIn](https://www.linkedin.com/posts/googledeepmind_introducing-codemender-activity-7380952307359973377--XQR).

**To use an analogy**, if existing AI was like an assistant writer who could answer simple questions like "Find the typo in this sentence," CodeMender equipped with Gemini Deep Think is like a veteran detective who ponders, "Trace why the logic in this sentence is flawed, analyze every scenario where a culprit could break in, and restructure the logical framework." Thanks to this, it can resolve even highly complex and serious security flaws without missing a beat [Google DeepMind launches CodeMender agent for AI code security](https://yourstory.com/ai-story/deepmind-codemender-ai-code-security).

### 2. It's not just a quick fix; it performs a 'fundamental constitutional improvement'
While typical repairs are like putting a band-aid over a hole, CodeMender goes a step further. When it discovers old code structures or APIs (Application Programming Interfaces, agreed-upon pathways for programs to exchange information) that are vulnerable to security risks, it completely rewrites them into newer, safer, and more robust structures [Introducing CodeMender: an AI agent for code security](https://deepmind.google/blog/introducing-codemender-an-ai-agent-for-code-security/).

In technical terms, this is called **'Proactive Hardening'** [Meet CodeMender: The Next Frontier in AI-Driven Code Security](https://tech-now.io/en/blogs/meet-codemender-the-next-frontier-in-ai-driven-code-security). **In simple terms**, it's similar to a chef who doesn't just pick out spoiled ingredients but suggests, "This recipe is inherently prone to food spoiling, so let's change it to a new cooking method that maintains freshness for a long time."

### 3. A 'cautious repairman' working in harmony with humans
Since AI is fixing code on its own, you might worry, "What if the AI makes a mistake and breaks the program?" That's why CodeMender goes through a very thorough **'multi-stage verification process.'** The repair code proposed by the AI is checked several times through simulations to ensure it is truly safe, and ultimately, **human expert developers directly review every repair piece** before it is applied to the actual program [Google DeepMind launches CodeMender agent for AI code security](https://yourstory.com/ai-story/deepmind-codemender-ai-code-security). It's a fantastic piece of teamwork where the lightning-fast speed of AI meets the cautious judgment of humans.

## Current status: How good is CodeMender?

CodeMender has already moved beyond the lab and is proving its value in the real world.

- **72 successful real-world records**: While active in Google's internal projects over the past six months, it successfully resolved 72 security issues in the open-source field [Meet CodeMender: The Next Frontier in AI-Driven Code Security](https://tech-now.io/en/blogs/meet-codemender-the-next-frontier-in-ai-driven-code-security).
- **Handling massive projects with ease**: Even in projects with the vast 4.5 million lines of code mentioned earlier, CodeMender showed its ability to tirelessly examine every nook and cranny to find and fix security flaws [Meet CodeMender: The Next Frontier in AI-Driven Code Security](https://tech-now.io/en/blogs/meet-codemender-the-next-frontier-in-ai-driven-code-security).
- **Responding at the speed of light**: By processing security diagnosis and repairs—which used to take humans days or weeks—in an instant, it has enabled 'ultra-fast defense' that sets up shields before a hacker can even prepare an attack [Google DeepMind's CodeMender arrives: AI agent guarantees unbreakable code security and real-time bug fixes](https://economictimes.indiatimes.com/ai/ai-insights/google-deepminds-codemender-arrives-ai-agent-guarantees-unbreakable-code-security-and-real-time-bug-fixes/articleshow/124597476.cms).

## Future outlook: A shift in the security paradigm

The emergence of CodeMender means more than just adding one 'convenient tool.' Along with CodeMender, Google is strengthening new security guidelines like 'SAIF 2.0' to make the security of autonomous systems even more robust [Everything You Need to Know About Google’s CodeMender](https://www.allaboutai.com/ai-news/everything-you-need-to-know-about-google-codemender/).

**Just imagine.** In the near future, when we download an app or use a website, an AI sheriff will guarantee in real-time that "The code for this service was perfectly checked by AI one minute ago and is safe." It will also become routine to see AI standing by as a developer writes a line of code, kindly advising, "That part is risky for security, why not write it this way instead?"

Through these changes, we will enjoy a digital daily life that is much freer and safer from threats like personal information leaks or financial hacking incidents. Can you trust software protected by an AI sheriff? Expectations are high for how this amazing change—where technology makes up for human error—will make our society safer.
