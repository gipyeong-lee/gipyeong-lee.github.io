# AI Signed My Commits Without Permission? The Claude Code Change That Surprised Developers

Imagine this: You are a meticulous developer. You want to manage every record of your work yourself, so you have even disabled the 'co-authored by' signature feature that AI tools often automatically add. How would you feel if, one day, you discovered a signature line you didn't write staring back at you in your commit message?

Recently, on the developer community Hacker News, voices of concern have been raised regarding a sudden change in the AI coding tool 'Claude Code.' This is due to a so-called 'session signature' feature that automatically adds AI-related information to project records without the user's explicit consent. What exactly is going on?

## Why Does This Matter?

This controversy poses an important question: "How much automation in AI tools should be permitted?" To a developer, a commit message is a sacred record tracking code changes. Having an AI leave its mark behind the user's back is being received not just as a minor feature addition, but as an issue of control over the developer's project and trust in security. ## Understanding Simply

First, we need to know what 'Claude Code' is. Claude Code is an official AI command-line interface (CLI, a method where users control a computer by typing text commands) tool created by Anthropic. Simply put, if you ask an AI in your terminal, "Solve this code problem," it is an 'AI development assistant' that analyzes the entire code structure, fixes it itself, and even creates a pull request (PR, a request to modify code). [Source: ClaudeCode by Anthropic | AI Coding Agent, Terminal, IDE](https://claude.com/product/claude-code)

When such a smart assistant performs tasks, previously, a 'co-authored by' tag could only be added if the user wanted it. However, in a recent update, the default settings were changed so that session link information from the conversation with the AI is automatically added to the end of the commit message, even if the user has turned off that tag. [Source: Tell HN: Claude Code appends new ...](https://weyouthster.blogspot.com/2026/09/new-ask-hacker-news-story-tell-hn.html)

To use a metaphor, it's like a gallery employee secretly sticking a 'This painting was made with an AI assistant' sticker on a painting made by an artist. The artist wants to remain the subject of their own work, but the system has forced the recording of AI involvement.

## How Much Can Be Automated?

Claude Code is a very powerful tool. Without the user needing to select the project structure themselves, the AI figures out dependencies (other code or libraries needed for the program to run) on its own, and you can even install sub-agents (assistant AI) or special technical skills created by the community to extend functionality. [Source: ClaudeCode by Anthropic | AI Coding Agent, Terminal, IDE](https://claude.com/product/claude-code), [Source: ClaudeSkills Directory — Browse 23,600+ ClaudeCodeSkills](https://claudemarketplaces.com/skills), [Source: Claude Code Agents](https://subagents.cc/)

However, as much as it is powerful, it also requires caution from the user. Claude Code can be used in various environments, from individual Pro or Max plan users to enterprise team plan users, but the fact that tool settings can change without notice or behave in unexpected ways is causing significant wariness among developers. [Source: Use Claude Code with your Pro or Max plan](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)

## What Will Happen in the Future?

As technology advances, AI assistants will become smarter and handle more tasks on their own. However, when that 'on their own' territory begins to infringe upon user rights, user trust collapses. In the future, when developers choose AI tools, 'how much they respect user settings' will become as important a criterion as how many features they provide.

For the time being, a 'digital administrator's' stance is needed: thoroughly checking the update history of AI tools and regularly inspecting whether records have been changed without your permission.

## MindTickleBytes' AI Reporter Opinion

Convenience is not always good. The more a tool does for the user, the more essential it is for the sustainable growth of the AI ecosystem that the user feels they are in control of the tool. We are the masters using the technology, not automated recorders for the technology.
