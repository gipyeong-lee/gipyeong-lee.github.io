Imagine this: You turn on your computer to find your favorite cooking recipe. You click to use Google Chrome or another browser as you usually do, but the computer abruptly launches a different browser, claiming, "This dish tastes best when viewed in this browser." You might put up with it once or twice, but what if this happened every time?

Unfortunately, this is the inconvenience many Windows users are currently facing. 100 days ago, Mozilla, the developer of the Firefox web browser, issued a report pointing out Microsoft's "Edge-pushing" strategy, but sadly, the situation has not changed much. In fact, some say it has become even more sophisticated.

### Why does this matter?

A web browser is like the "front door" to the internet. It's where you manage passwords, maintain your browsing history, and create a web environment that suits your tastes. Therefore, choosing which front door to use is entirely a user's right.

However, Microsoft is using the Windows operating system and its generative AI, Copilot, to "guide" users into using Edge naturally. This goes beyond the issue of increasing browser market share; it is considered a serious problem because it demonstrates how big tech companies can manipulate users' autonomous choices. The Browser Choice Alliance criticizes these practices for limiting users' ability to control their own environment [Source: Dark patterns in Windows are steering users to Edge: Mozilla ...](https://www.theregister.com/os-platforms/2026/07/15/dark-patterns-in-windows-are-steering-users-to-edge-mozilla-commissioned-report/5271792).

### Easy to understand: 'The pre-arranged restaurant flow'

Simply put, Microsoft's strategy is similar to a restaurant owner who "guides customers to corner seats."

Normally, a customer should be able to sit wherever they want. However, the owner puts complex obstacles in the way from the entrance, preventing the customer from going where they want, and keeps only the lights leading to a specific corner seat (Edge) brightly lit.

With the transition to Windows 11, Microsoft has reinforced these design tricks. The AI assistant 'Copilot' is a prime example. When a user clicks a web link while chatting with Copilot, Copilot ignores the default browser the user pre-set and opens the page in its own 'side panel' [Source: Mozilla says Microsoft still steers Windows users towards Edge...](https://www.hindustantimes.com/business/mozilla-says-microsoft-still-steers-windows-users-towards-edge-except-in-the-eu-101791367540045.html). In other words, you have to view information not in the browser you chose, but in the space Microsoft has designated.

### Where do we stand?

In the current digital environment, users' rights are increasingly being eroded by corporate algorithms. Many users utilize Copilot or Windows' recommendation features for convenience, but they are paying for it with their "freedom of choice." We need to critically examine whether the technical tools we use every day are truly for the user, or if they act as "fences" to trap people into the company's own services.

### Report card after 100 days: More sophisticated induction

According to research conducted by Mozilla, although this practice was first made public 100 days ago through the 'Over the Edge 2.0' report, Microsoft has made no improvements [Source: 100 Days Later: Microsoft still undermines browser choice](https://daily.dev/posts/100-days-later-microsoft-still-undermines-browser-choice-b7schgjmq).

Furthermore, the latest research results show that the situation actually worsened in 2026. The attempts to draw users to Edge using the transition to Windows 11 or new features like Copilot use much more aggressive design patterns than before [Source: 100 Days Later: Microsoft still undermines browser choice](https://blog.mozilla.org/en/mozilla/over-the-edge-2-100-days-later/). Excluding Europe, where legal regulations are strong, Windows users in many parts of the world remain exposed to this forced induction environment [Source: Tux Machines — Web Browsers: Opera, Chrome, and Mozilla](https://news.tuxmachines.org/n/2026/10/08/Web-Browsers-Opera-Chrome-and-Mozilla.shtml).

### What will happen in the future?

If the development of technology flows in a direction where it does not help humans but rather "manipulates" them into using a company's specific product, this is a very dangerous sign. Mozilla's report warns that Microsoft continues to use "design tricks" that link Windows, Copilot, and the Bing search service to steer users toward Edge [Source: Microsoft Persists in Undermining Browser Choice in Windows ...](https://o-server.main.jp/hacker-news/en/articles/2026/10/07/microsoft-persists-in-undermining-browser-choice-in-windows-mozil-50000431.html).

Consumers need to become sharper. If you feel like an unwanted browser keeps popping up while using your computer, or that your choices are being subtly blocked, it is not a coincidence. To sound an alarm against these corporate strategies, it is important for users to actively exercise their browser settings rights and consistently voice their opposition to monopolistic corporate practices.

When the browser we choose becomes the true window through which we view the internet, a healthy digital environment will finally begin.
