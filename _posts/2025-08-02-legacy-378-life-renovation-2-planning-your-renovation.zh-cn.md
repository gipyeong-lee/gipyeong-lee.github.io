<h2>
2. 愿景与目标
</h2>
<ol>
<li>
<strong>
投资基础
</strong>
— 结构、隔热、防水难以后期修补，应优先处理。
</li>
<li>
<strong>
降低维护成本
</strong>
— 使用高效门窗·设施，最大化自然采光与通风。
</li>
<li>
<strong>
DIY 完整性
</strong>
— 将工作步骤细分，设计为即便在周末或夜间也能进行的操作流程。
</li>
</ol>
<blockquote>
<p>
<span>
<p>
<strong>
必须知晓
</strong>
目标模糊会导致预算与进度全面失控。
通过区分 <em>Need (必需) / Want (想要)</em> 来建立决策标准。
</p>
</span>
</p>
</blockquote>

<h2>
3. 现状评估
</h2>
<h3>
3.1 屋顶（瓦片·屋顶防水）
</h3>
<ul>
<li>
检查瓦片下方防水卷材状态 → 标记受损部位。
</li>
<li>
计算屋顶聚氨酯 / 聚脲涂层所需面积。
</li>
</ul>
<h3>
3.2 外墙
</h3>
<ul>
<li>
使用热成像仪（可租借）探测结露·漏水点。
</li>
<li>
记录隔热材料厚度 / 现有饰面层厚度。
</li>
</ul>
<h3>
3.3 内部
</h3>
<ul>
<li>
电气线路 — 检查是否裸露或外皮开裂。
</li>
<li>
给排水 — 记录主管道直径及回流痕迹。
</li>
</ul>
<p>
将照片、尺寸、笔记保存至
<strong>
Google Drive › Renovation › Survey
</strong>
文件夹中。
</p>
<hr>
<h2>
4. 法律与结构限制
</h2>
<ol>
<li>
<strong>
用途区域 / 容积率
</strong>
：在区政府建筑科查阅相关文件。
</li>
<li>
<strong>
识别承重墙
</strong>
：标记木结构桁架·梁的位置。
</li>
<li>
<strong>
屋顶防水许可
</strong>
：妥善保管防水层性能认证证书（用于保修保险）。
</li>
</ol>
