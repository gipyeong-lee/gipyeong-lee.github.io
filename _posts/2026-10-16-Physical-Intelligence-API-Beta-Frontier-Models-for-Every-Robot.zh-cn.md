想象一下：早上起床，你对机器人说“请挑选出今天成熟的草莓并放入篮子里”，或者向工厂机器人下令“把这些服务器零件组装起来”。在此之前，要教机器人完成这些任务，需要无数工程师、庞大的计算机设备以及长达数年的编程工作。但现在，就像向AI下令作画一样，我们已经迈入了一个可以更轻松、更智能地训练机器人的时代。

近期，物理智能（Physical Intelligence, π）公开了API测试服务，允许机器人开发者直接调用其最新的机器人学习模型（[Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/)）。这项开启机器人学新篇章的消息将带来哪些变革？为什么说它是革命性的？让我们来深入浅出地了解一下。

## 为什么这很重要？

机器人最初是为了代替人类完成困难或危险的工作而制造的。然而在现实中，驱动机器人的过程依然背负着高昂成本和技术门槛的巨大挑战（[Building safe physical AI: Open questions, risks, and... — EA Forum](https://forum.effectivealtruism.org/posts/EyNDeibxSymBWrRsr/building-safe-physical-ai-open-questions-risks-and-a-call)）。

到目前为止，机器人开发者为了让机器人变得聪明，必须从零开始构建复杂的自定义机器学习系统。这就像一个想学做菜的人，必须先自己买下一座农场，甚至还要亲自发明烹饪工具一样。本次公开的API测试版旨在实现“机器人学习的普及化”。现在，机器人制造者可以在物理智能已经打下的坚实技术基础上，更快速、更高效地训练自己的机器人（[Physical Intelligence Opens API Beta for Its Robot Models](https://www.robotaigeek.com/news/physical-intelligence-opens-api-beta-for-robot-foundation-models/)）。

## 通俗理解：机器人的“基础教育”过程

物理智能（Physical Intelligence）是一支致力于开发通用人工智能模型的团队，旨在让任何机器人都能执行任何任务（[PhysicalIntelligence(π)](https://www.pi.website/)）。打个比方，他们正在为机器人制造通用的“大脑”。

通过本次公开的API测试服务，开发者可以使用“π0”和“π0.5”这两个核心模型（[Physical Intelligence opens Pi API beta for robot training ...](https://www.blackscarab.ai/news/physical-intelligence-pi-api-beta)）。

其运行方式大致分为三个阶段：
1. **数据上传**：就像孩子通过模仿父母的行为来学习一样，开发者将机器人执行特定任务所需的“行为数据”上传至系统。
2. **微调（Fine-tuning）**：在物理智能已经打好的基础学习模型（π0, π0.5）之上，开发者植入自己上传的数据，从而教导机器人掌握特定的技能。
3. **云端托管**：不需要为每台机器人配备昂贵的运算设备。训练好的模型在云端驱动，机器人随时可以调用（[Physical Intelligence opens its π0 robot models to everyone via an API](https://robrief.com/en/companies/physical-intelligence)）。

简而言之，机器人已经掌握了基本的物理定律和运动基础（相当于小学教育），通过API只需额外学习特定任务（相当于专业教育）即可。

## 现状：进展到什么程度了？

实验已经在多个领域展开。物理智能通过此次公开展示了无人驾驶轮式装载机（重型设备）、草莓采摘、服务器组装以及对金属零件粗糙表面进行平滑处理的去毛刺作业等（[Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/)）。

这项技术的核心在于“通用性”。它不仅仅让特定的机器人变得出色，而是帮助相同的AI模型应用到不同形态的机器人身上，使其能够自主判断并采取行动（[Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/)）。不过，由于目前仍处于测试阶段，并非所有开发者都能不受限制地使用，而是通过等待名单逐步开放访问权限（[Physical Intelligence opens Pi API beta for robot training ...](https://www.blackscarab.ai/news/physical-intelligence-pi-api-beta)）。

## 未来展望

我们正目睹通过机器人解决劳动力短缺这一难题的可能性（[Building safe physical AI: Open questions, risks, and... — EA Forum](https://forum.effectivealtruism.org/posts/EyNDeibxSymBWrRsr/building-safe-physical-ai-open-questions-risks-and-a-call)）。未来，与其手动输入数千行代码，不如通过向机器人提供“数据”来让其承担专业的业务。不久之后，我们将在日常生活中习以为常地看到机器人采摘餐桌上的草莓，并亲手组装我们使用的计算机服务器。
