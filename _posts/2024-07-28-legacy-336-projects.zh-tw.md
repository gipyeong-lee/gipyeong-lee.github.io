<h4>
📝 使用方法說明
</h4>
<ol>
<li>
<b>
綠肥作物：
</b>
🌿
<ul>
<li>
<b>
方法：
</b>
在作物周圍種植綠肥作物，待長大後翻耕入土，與土壤混合。這能為土壤補充有機物和養分。
</li>
</ul>
</li>
<li>
<b>
有機物：
</b>
♻️
<ul>
<li>
<b>
方法：
</b>
將堆肥、廚餘或植物殘渣拌入作物周圍的土壤中，以提高土壤肥力。
</li>
</ul>
</li>
<li>
<b>
木灰：
</b>
?
<ul>
<li>
<b>
方法：
</b>
將鹼性的木灰少量撒在作物周圍的土壤上，以調節酸鹼值並補充所需的微量元素。
</li>
</ul>
</li>
<li>
<b>
骨粉：
</b>
🦴
<ul>
<li>
<b>
方法：
</b>
將動物骨頭磨碎製成骨粉，拌入作物周圍的土壤中以補充磷酸。
</li>
</ul>
</li>
<li>
<b>
海藻：
</b>
🌊
<ul>
<li>
<b>
方法：
</b>
將海藻進行堆肥化，拌入作物周圍的土壤中，以供應磷酸及多種營養素。
</li>
</ul>
</li>
<li>
<b>
磷礦石：
</b>
🪨
<ul>
<li>
<b>
方法：
</b>
將天然磷酸鹽礦物與作物周圍的土壤混合，使其緩慢釋放磷酸。
</li>
</ul>
</li>
<li>
<b>
香蕉皮：
</b>
🍌
<ul>
<li>
<b>
方法：
</b>
將香蕉皮乾燥後磨成粉末，拌入作物周圍的土壤中以補充鉀。
</li>
</ul>
</li>
<li>
<b>
蛋殼：
</b>
🥚
<ul>
<li>
<b>
方法：
</b>
將蛋殼乾燥後磨成粉末，拌入作物周圍的土壤中以補充鈣。
</li>
</ul>
</li>
<li>
<b>
灌溉管理：
</b>
💧
<ul>
<li>
<b>
方法：
</b>
為了防止鹽分累積，透過適量的水分管理來控制土壤的電導度。
</li>
</ul>
</li>
</ol>

<p>
即使不使用肥料，也能透過天然方法解決土壤問題並種植出健康的作物。請試著靈活運用綠肥作物、有機物、木灰等多種自然資源，實踐永續農業。健康的土壤是健康作物的基礎。願大家透過永續的方式管理土壤，獲得豐碩的收穫。🌱
