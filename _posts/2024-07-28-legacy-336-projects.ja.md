<h4>
? 使用方法の説明
</h4>
<ol>
<li>
<b>
緑肥作物：
</b>
?
<ul>
<li>
<b>
方法：
</b>
作物の周辺に緑肥作物を植え、成長した後にすき込んで土壌に混ぜ合わせます。これにより有機物と栄養素を土壌に供給します。
</li>
</ul>
</li>
<li>
<b>
有機物：
</b>
♻️
<ul>
<li>
<b>
方法：
</b>
堆肥や生ゴミ、植物の残渣を作物周辺の土に混ぜて土壌の肥沃度を高めます。
</li>
</ul>
</li>
<li>
<b>
木灰：
</b>
?
<ul>
<li>
<b>
方法：
</b>
アルカリ性の木灰を少量、作物周辺の土に撒いて酸度を調節し、必要な微量栄養素を補います。
</li>
</ul>
</li>
<li>
<b>
骨粉：
</b>
?
<ul>
<li>
<b>
方法：
</b>
動物の骨を粉砕して作った骨粉を作物周辺の土に混ぜてリン酸を補います。
</li>
</ul>
</li>
<li>
<b>
海藻類：
</b>
?
<ul>
<li>
<b>
方法：
</b>
海藻類を堆肥化して作物周辺の土に混ぜ、リン酸と多様な栄養素を供給します。
</li>
</ul>
</li>
<li>
<b>
リン鉱石：
</b>
?
<ul>
<li>
<b>
方法：
</b>
自然のリン酸塩鉱物を作物周辺の土に混ぜ、リン酸を徐々に放出させます。
</li>
</ul>
</li>
<li>
<b>
バナナの皮：
</b>
?
<ul>
<li>
<b>
方法：
</b>
バナナの皮を乾燥させて粉末状にした後、作物周辺の土に混ぜてカリウムを補います。
</li>
</ul>
</li>
<li>
<b>
卵の殻：
</b>
?
<ul>
<li>
<b>
方法：
</b>
卵の殻を乾燥させて粉末状にした後、作物周辺の土に混ぜてカルシウムを補います。
</li>
</ul>
</li>
<li>
<b>
灌漑管理：
</b>
?
<ul>
<li>
<b>
方法：
</b>
塩類集積を防ぐため、適切な量の水やりを行って土壌の電気伝導度を管理します。
</li>
</ul>
</li>
</ol>
