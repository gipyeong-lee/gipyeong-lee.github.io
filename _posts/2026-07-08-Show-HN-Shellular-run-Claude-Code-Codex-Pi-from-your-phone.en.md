## Easy to understand: A 'transparent development room' inside your smartphone

Simply put, Shellular can be described as technology that turns your smartphone into a 'transparent remote control' for your PC.

To use an analogy, it’s like a 'filter' in a photo editing app. You leave the essence of the photo as it is, but the filter changes the perspective or atmosphere with which you view it. Shellular is the same; the powerful PC environment where the actual code runs is maintained, but you enter that environment to work through the filter of your smartphone.

Furthermore, the way it utilizes AI agents is no different from having a 'smart assistant' by your side. If you tell an AI assistant like Claude Code or Codex within the smartphone app, "Make this function more efficient," the assistant examines the code and proposes revisions.
