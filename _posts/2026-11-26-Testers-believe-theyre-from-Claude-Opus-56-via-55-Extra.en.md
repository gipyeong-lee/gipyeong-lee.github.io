First, it shows that **the pace of AI technology advancement is accelerating even more stealthily and rapidly than we expected**. Companies sometimes announce new products with major events, but beforehand, they often conduct hidden performance tests (A/B testing) targeting small groups of users in actual service environments. The astonishing performance improvements captured during this process serve as an important milestone to gauge how much smarter the AI assistants we will encounter in the future will be.

Second, the way we handle everyday tasks and content creation could change completely. If AI can implement a complete program or visual content purely through code based solely on imagination, without the help of complex external programs or design sources, a world where anyone can become a developer or animator with just a single idea is rapidly approaching [[Source 2, Source 3](https://www.testingcatalog.com/testers-share-early-results-possible-claude-opus-5-6/)].

## Current Status: What Was Discovered, and What Is the Truth?

So, what are the specific circumstances that testers are enthusiastic about? Recently, reports have poured in on social media platforms like X (formerly Twitter) that testers detected anomalies while using Anthropic's conversational chatbot service and developer tool Claude Code [[Source 1, Source 3](https://www.testingcatalog.com/testers-share-early-results-possible-claude-opus-5-6/)].

### 1. Hidden A/B Testing and 'Opus 5.5 Extra'
According to testers' analyses, complex Q&A currently submitted by some users is being routed and processed through a specific internal path called **Opus 5.5 Extra** [[Source 1, Source 3](https://www.testingcatalog.com/testers-share-early-results-possible-claude-opus-5-6/)]. Users strongly suspect that the entity behind this hidden route is an unannounced next-generation model, namely **Claude Opus 5.6** [[Source 1, Source 3](https://www.testingcatalog.com/testers-share-early-results-possible-claude-opus-5-6/)].

### 2. Animated Movies and 3D Worlds Implemented in Code
Practical developers and testers who experienced this mysterious route began sharing surprising results that were hard to imagine with existing models. Representative examples published on GitHub and elsewhere include writing an **entire animated movie using only pure Python code** without external image or video asset files, or creating a **complete 3D virtual space simulation using Three.js** (a technology library that makes web-based 3D graphics easy to handle) in a web browser without any external files [[Source 2, Source 3](https://www.testingcatalog.com/testers-share-early-results-possible-claude-opus-5-6/)]. This demonstrates that AI is perfectly simulating complex logic and visual structures in its mind beyond simple sentence writing.

### 3. The Tier of 'Claude Opus 5.5' as a Baseline
This rumor gains even more credibility because **Claude Opus 5.5**, the predecessor model officially released to the market, already demonstrated tremendous performance. Officially launched on September 22, 2026, Claude Opus 5.5 is a hybrid reasoning model designed to handle complex programming, long-term agent tasks, and demanding professional work [[Source 6, Source 9, Source 11](https://www.anthropic.com/claude/opus)]. 
- It supports a massive **context window of up to 1 million tokens** (the unit of text and data chunks that AI can read and understand at once), capable of digesting book-length material at once [[Source 6](https://www.anthropic.com/claude/opus)]. One million tokens correspond to several regular novels, perfectly remembering vast contexts without missing anything.
- Execution costs are a whopping **40% cheaper** compared to the previous-generation Opus 5 model, priced at around $4 per million input tokens and $20 for output [[Source 6, Source 11](https://www.anthropic.com/claude/opus)].
- Nevertheless, it boasts expert-level problem-solving capabilities matching or surpassing Claude Fable 5.1, the top performance line [[Source 6, Source 9, Source 11](https://www.anthropic.com/claude/opus)]. 

Based on such a solid version 5.5, expectations and speculations for the next version, 5.6, are further amplified.

### 4. The Fake Benchmark Graph Incident That Ended as a Happening
Of course, not all rumors are true. Amid the overheating of social media and tech communities, some benchmark (performance measurement) data leaked under the pretext of comparing the performance of the unreleased Opus 5.6 turned out to be **fake data created by someone arbitrarily drawing lines on OpenAI's existing performance graph** [[Source 8](https://tproger.ru/news/utechku-benchmarkov-claude-opus-5-6-dorisovali-na-grafik-openai)]. This was a happening driven by overheating performance expectations. However, aside from the fabricated graph uproar, the actual code results executed and shared directly by testers remain real and continue to amaze people [[Source 2, Source 3](https://www.testingcatalog.com/testers-share-early-results-possible-claude-opus-5-6/)].
