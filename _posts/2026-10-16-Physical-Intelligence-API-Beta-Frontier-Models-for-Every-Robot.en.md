Imagine waking up in the morning and telling a robot, "Select the strawberries to be harvested today and put them in a basket," or commanding a factory robot, "Assemble these server parts." Until now, teaching robots these tasks required countless engineers, massive computer equipment, and years of coding. But now, just like commanding an AI to draw a picture, we are entering an era where robots can be trained more easily and intelligently.

Recently, Physical Intelligence (π) released an API beta service that allows robot developers to directly utilize their latest robot learning models ([Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/)). Let’s look at why this news, which opens a new chapter in robotics, is revolutionary.

## Why Is This Important?

Robots were originally created to do jobs that are difficult or dangerous for humans. However, in reality, moving robots still faces huge challenges in terms of high costs and technical barriers ([Building safe physical AI: Open questions, risks, and... — EA Forum](https://forum.effectivealtruism.org/posts/EyNDeibxSymBWrRsr/building-safe-physical-ai-open-questions-risks-and-a-call)).

Until now, to make a single robot intelligent, developers had to build complex machine learning systems from scratch. It was like wanting to learn to cook but having to buy a farm and invent the cooking tools yourself. The API beta released this time aims for this "democratization of robot learning." Robot makers can now train their robots much faster and more efficiently on the solid technical foundation already laid by Physical Intelligence ([Physical Intelligence Opens API Beta for Its Robot Models](https://www.robotaigeek.com/news/physical-intelligence-opens-api-beta-for-robot-foundation-models/)).

## Easy Understanding: The 'Basic Education' Process for Robots

Physical Intelligence is a team developing general-purpose artificial intelligence models that allow any robot to perform any task ([PhysicalIntelligence(π)](https://www.pi.website/)). Simply put, they are creating a common 'brain' for robots.

Through the API beta service released, developers can use two core models, 'π0' and 'π0.5' ([Physical Intelligence opens Pi API beta for robot training ...](https://www.blackscarab.ai/news/physical-intelligence-pi-api-beta)).

The working process consists of three main stages:
1. **Data Upload**: Just like a child learns by watching their parents' actions, developers upload 'behavioral data' needed for the robot to perform a specific task to the system.
2. **Fine-tuning**: Developers teach the robot specific skills by layering the uploaded data onto the foundation learning models (π0, π0.5) already established by Physical Intelligence.
3. **Cloud Hosting**: There is no need to attach expensive computing equipment to every robot. The trained model runs in the cloud, allowing the robot to call and use it at any time ([Physical Intelligence opens its π0 robot models to everyone via an API](https://robrief.com/en/companies/physical-intelligence)).

In short, the robot has already learned the basic laws of physics and the foundations of movement (elementary education), and it only needs to learn specific tasks (specialized education) additionally through the API.

## Current Status: How Far Have We Come?

Experiments are already underway in various fields. Through this release, Physical Intelligence has demonstrated tasks such as unmanned wheel loaders (heavy equipment), strawberry harvesting, server assembly, and deburring, which smooths out the rough surfaces of metal parts ([Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/)).

The core of this technology is 'universality.' It helps robots judge and move on their own even when the same AI model is applied to robots of different shapes, rather than just performing well on specific robots ([Physical Intelligence Opens Pi API Beta for Robot Foundation Models](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/)). However, as it is still in the beta stage, access is not provided to all developers without restrictions and is being offered gradually through a waitlist ([Physical Intelligence opens Pi API beta for robot training ...](https://www.blackscarab.ai/news/physical-intelligence-pi-api-beta)).

## What Happens Next?

We are now seeing the possibility of overcoming the challenge of labor shortages through robots ([Building safe physical AI: Open questions, risks, and... — EA Forum](https://forum.effectivealtruism.org/posts/EyNDeibxSymBWrRsr/building-safe-physical-ai-open-questions-risks-and-a-call)). In the future, instead of manually inputting thousands of lines of code into a robot, an era will come where professional tasks can be entrusted to robots using only the 'data' that instructs them. Soon, we will see robots harvesting strawberries for our tables and assembling the computer servers we use as a daily occurrence.
