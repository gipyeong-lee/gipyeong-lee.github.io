**想像一下。** 在一個悠閒的週末，你在氣氛佳的山中咖啡廳打開 MacBook，準備寫一篇優美的散文。但糟糕的是，完全收不到 Wi-Fi 訊號。我們常用的 ChatGPT 等聰明的人工智慧，一旦斷網就會立刻癱瘓。但是，如果你的 MacBook 裡已經住著一位聰明的「秘密作家」，即使沒有網路，也能閱讀你過去寫下的所有日記，幫你理出寫作方向並潤飾生硬的句子，那會是什麼感覺呢？

這個魔法般的故事現在已成為現實。最近由開發者 John Taverna 公開的 **「CyberWriter」**，是一款挖掘 Apple 悄悄藏在 macOS 中的 AI 技術，所打造出的全新寫作工具 [cyberWriterApp - App Store](https://apps.apple.com/us/app/cyberwriter/id6758079118?mt=12)。今天，我們就來揭開這位聰明「隱士作家」的神祕技術面紗，看看它為什麼能成為改變我們寫作習慣的遊戲規則改變者。

## 1. 這為什麼很重要？ (Why It Matters)

我們平時使用的人工智慧 (AI) 大多是「雲端方式」。**簡單來說**，就是將我寫的文字傳送到巨大企業的總部伺服器，然後接收回傳的答案。這個過程存在兩個巨大的障礙。

第一是**徹底保密的侷限性**。當向 AI 詢問公司機密或難以向他人啟齒的私人煩惱時，難免會擔心「這些內容如果留在企業伺服器該怎麼辦？」。第二是**每個月的支出**。每個月必須支付訂閱費，或是根據使用量付費的複雜結算方式，是一筆不小的負擔。

CyberWriter 透過 **裝置端 (On-Device) AI** 技術正面突破了這些問題。AI 不在網路世界運行，而是僅在我的 MacBook 這台裝置內部運作。
*   **完美的隱私保護**：我的文字和筆記絕不會離開我的 MacBook 半步。個人的秘密日記將得到安全保護 [CyberWriter，一款 Markdown 編輯器... - SaaS Insight](https://roipad.com/saas-metrics/view/hn_47833747/show-hn-cyberwriter-a-md-editor-built-on-apple-s-barely-used-on-device-ai)。
*   **無額外費用的無限 AI**：沒有每月訂閱費，也沒有依使用量計費（Token 費用）。因為它直接使用 Apple 已經內建在裝置中的人工智慧 [cyberWriter - 適用於 macOS 的原生 Markdown 戰力](https://cyberwriter.app/)。
*   **在飛機上也能使用**：即使在完全沒有網路的飛機上或深山中，也能在 AI 的幫助下完成創作 [cyberWriter - 適用於 macOS 的原生 Markdown 戰力](https://cyberwriter.app/)。

Apple 將此稱為「屬於我們所有人的 AI (AI for the rest of us)」 [AppleIntelligence - Apple](https://www.apple.com/apple-intelligence/)。即使沒有專業的程式設計知識，任何人都能充分發揮裝置所擁有的智慧。

## 2. 輕鬆理解：進入 MacBook 的「30 億個聰明細胞」

CyberWriter 寫作如此聰明的秘訣是什麼？這款 App 是基於從 macOS 26 版本開始正式公開的 Apple **基礎模型 (Foundation Model)** [歡迎來到 Tolexty 的部落格：Show HN: CyberWriter – 建立在 Apple（鮮少使用）裝置端 AI 之上的 .md 編輯器](https://tolexty.blogspot.com/2026/04/show-hn-cyberwriter-md-editor-built-on.html)。你可以將基礎模型想像成「所有智慧基礎的巨大大腦」。

### 大腦中的 30 億個開關 (3B Parameters)
這個模型中包含約 30 億個「參數 (Parameters)」 [CyberWriter，一款 Markdown 編輯器... - SaaS Insight](https://roipad.com/saas-metrics/view/hn_47833747/show-hn-cyberwriter-a-md-editor-built-on-apple-s-barely-used-on-device-ai)。**比喻來說**，就像 AI 的腦海中有 30 億個聰明的細胞或微小的開關，能夠掌握前後文脈絡，並精準預測下一個會出現的單字。雖然比雲端的巨大 AI（擁有數兆個參數）規模小，但要在 MacBook 中快速且高效地輔助寫作，其實力已綽綽有餘。

### 記住我筆記的「知識地圖」 (Embedding)
CyberWriter 不僅僅是幫忙寫作，它還能「理解」我過去寫下的無數筆記。這是怎麼辦到的呢？這要歸功於 **嵌入 (Embedding)** 技術。

嵌入是將文字的意義轉換為數字，並像地圖上的座標一樣標示出來的技術 [CyberWriter，一款 Markdown 編輯器... - SaaS Insight](https://roipad.com/saas-metrics/view/hn_47833747/show-hn-cyberwriter-a-md-editor-built-on-apple-s-barely-used-on-device-ai)。**例如**，「蘋果」和「梨子」意義相近，因此會被配置在地圖上非常接近的位置；而「蘋果」和「汽車」則會配置在非常遙遠的位置。CyberWriter 利用這項技術將我的筆記細心地整理在意義地圖上。多虧於此，當我詢問「去年去濟州島旅遊時吃的餐廳叫什麼名字？」時，AI 能瞬間搜尋這張地圖，找出相關內容並回答 [cyberWriter - 適用於 macOS 的原生 Markdown 戰力](https://cyberwriter.app/)。

## 3. 主要功能：AI 在指尖跳舞

CyberWriter 不僅僅是一個日記本，它更是一個能輔助專業等級寫作的 **Markdown** 編輯器 [GitHub - uncSoft/cyberwriter-app: cyberWriter - 原生 macOS Markdown 編輯器](https://github.com/uncsoft/cyberwriter-app)。Markdown 是一種透過一個「#」建立標題或用「*」粗體化文字等，像寫程式一樣簡單快速裝飾文件的方式。

*   **直接與你的筆記庫對話 (Chat with your vault)**：透過「檢索增強生成 (RAG)」技術，可以讓 AI 閱讀儲存在電腦中的各種文件（.md, .pdf, .csv 等） [cyberWriter - 適用於 macOS 的原生 Markdown 戰力](https://cyberwriter.app/)。只需一句「幫我總結我的筆記」，數百頁的記錄便能一目了然。
*   **即時填充句子 (Stream-to-editor)**：不需要枯燥地等待 AI 完成所有回答。你可以親眼看到 AI 在游標處即時逐字打字的樣子 [cyberWriter - 適用於 macOS 的原生 Markdown 戰力](https://cyberwriter.app/)。感覺就像有一位透明人作家在代為打字。
*   **神奇快捷鍵 (Cmd + J)**：在寫作卡住的地方選取範圍，然後按下 `Cmd + J`。你可以立即要求總結句子、將口氣變得優雅，或是請它將深奧的概念解釋得像小學生也能聽懂 [cyberWriter - 適用於 macOS 的原生 Markdown 戰力](https://cyberwriter.app/)。
*   **專業工具**：它還內建了能繪製複雜組織圖的 **Mermaid**，以及能整齊呈現困難數學公式的 **KaTeX** 功能。對於大學生或研究人員來說，也是非常實用的工具 [GitHub - uncSoft/cyberwriter-app: cyberWriter - 原生 macOS Markdown 編輯器](https://github.com/uncsoft/cyberwriter-app)。

## 5. 未來會如何？ (What's Next)

CyberWriter 的出現意味著人工智慧不再是「遠在天邊的超能力」，而是成為電腦中內建的「理所當然的鉛筆」。未來，不僅是寫作，影像編輯、行程管理等所有領域都將湧現大量既聰明運行又無需將個人資訊傳送到外部的 App。

你的 MacBook 現在不再僅僅是一台機器。它是記住你所有想法、並與你的文風日益相似的可靠共同作者。從今天開始，何不與 CyberWriter 一起打造屬於你自己的「安全知識倉庫」呢？
