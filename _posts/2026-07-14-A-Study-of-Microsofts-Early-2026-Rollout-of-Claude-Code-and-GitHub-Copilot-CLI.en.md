# Why Microsoft Chose Its Own Copilot CLI Over AI Coding Tool Claude Code

Imagine having an artificial intelligence (AI) assistant by your side, quickly helping you with complex coding tasks. Recently, such AI coding tools have become common in the software development industry, with tech giants like Microsoft actively utilizing them. However, news has emerged that Microsoft is reducing its internal use of Anthropic's AI coding tool, 'Claude Code,' and is largely transitioning to its own 'GitHub Copilot CLI.' [Source 3, Source 4] Why did Microsoft make this decision? Is it a simple internal policy change, or a significant signal reflecting a major trend in the AI market?

## Why is this important?

This news has significant implications even for non-experts. First, it shows that the 'cost' of AI technology is more serious than generally perceived. The main reason Microsoft is reducing its use of Claude Code is 'high cost' [Source 5, Source 7]. Simply put, just like parents might decide to homeschool their child due to expensive tuition, large corporations also feel burdened by AI tool usage fees. At an organizational scale, the 'token usage' cost for Agentic Command Line Tools (AI tools that autonomously perform complex tasks based on user commands) can amount to millions of dollars annually [Source 1, Source 2]. Here, 'token' is the smallest unit AI processes text with, where our words and sentences are converted into tokens for calculation. The more AI is used, the higher the token cost. In fact, companies like Uber once experienced AI budgets exceeding $1.2 billion [Source 7]. Such unseen AI usage fees reaching astronomical levels are a crucial consideration for businesses.

Second, this demonstrates a strategic move by companies to become 'self-reliant' in AI technology. Microsoft is now showing its intention to secure technological leadership by transitioning to its self-developed AI tools rather than relying on external ones [Source 6]. This serves as an important indicator to predict how the competitive landscape in the AI market will change in the long run. To draw an analogy, it's similar to a car company that used to source key parts externally, but now switches to in-house production to save costs and achieve technological independence. This move to internalize core AI technological capabilities could become a strategic direction many companies will follow in the future.

## Easy to understand

So, what exactly are 'Claude Code,' which Microsoft is reducing its use of, and the 'GitHub Copilot CLI,' to which it is transitioning?

'Claude Code' is an AI-powered coding assistant developed by Anthropic. It's a tool that helps developers efficiently perform various coding tasks such as writing code, debugging, and documentation [Source 8, Source 13]. You can compare it to an experienced programmer helping you write code or find errors by your side. Developers were able to complete code faster and more accurately with Claude Code.

On the other hand, 'GitHub Copilot CLI' is an AI coding tool provided by GitHub, which Microsoft acquired. 'CLI' stands for Command Line Interface, referring to a method of interacting with a computer by directly entering commands via keyboard, instead of using a mouse-driven graphical interface (GUI). GitHub Copilot is already famous for its code auto-completion feature in code editors (like Visual Studio Code) [Source 9], and the 'CLI' version further acts as an agent assisting with overall coding tasks in a command-line environment [Source 8]. You can think of it as a versatile workbench that gathers various coding tools in one place. GitHub Copilot CLI supports developers in generating and managing code with AI assistance directly from the command line.

Microsoft's transition from Claude Code to GitHub Copilot CLI is more than just switching from a third-party product to an in-house one. Microsoft plans to move thousands of Experiences + Devices engineers from Claude Code to GitHub Copilot CLI by June 30, 2026 [Source 3, Source 7]. This is a strategic move to address massive AI usage costs internally and strengthen its own AI technology ecosystem [Source 5, Source 6]. It's like a film production company using its own special effects team instead of an expensive external studio to save costs and increase control over the final product's quality. This move demonstrates Microsoft's resolve to further solidify its influence in the AI sector.

## Current situation

Microsoft is currently canceling Anthropic's Claude Code licenses and encouraging engineers to use GitHub Copilot CLI [Source 5, Source 6, Source 7]. This internal transition is expected to be completed by June 30, 2026 [Source 3, Source 7]. This process will serve as an important case study for re-evaluating the economic feasibility and strategic importance of AI adoption in large organizations, rather than a simple tool replacement [Source 1, Source 2]. From an engineer's perspective, adapting to a new tool instead of a familiar AI tool will be a challenge, but in the long run, they are expected to experience a more integrated AI experience within the Microsoft ecosystem. This change is anticipated to contribute to streamlining development workflows and optimizing costs within Microsoft.

## What's next?

Microsoft's decision is expected to have a significant impact on the AI coding tool market. Other companies will also prioritize cost-efficiency and strengthening their own technological capabilities when adopting AI tools. This will demand price competitiveness and differentiated value offerings from AI service providers, and it could be an opportunity for companies with in-house AI development capabilities to strengthen their market dominance. Additionally, developers will face deeper considerations about which AI coding tool to choose. The decision of whether to be dependent on a specific company's ecosystem or to flexibly utilize various tools will become more crucial. Ultimately, these changes will further accelerate the development and innovation of AI coding tools.
