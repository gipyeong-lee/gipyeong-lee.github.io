<h2>
2. 願景與目標
</h2>
<ol>
<li>
<strong>
投資基礎
</strong>
— 結構、隔熱與防水難以事後補救，應優先處理。
</li>
<li>
<strong>
節省維護成本
</strong>
— 採用高效率窗戶與設備，極大化自然採光與通風。
</li>
<li>
<strong>
DIY 的完整性
</strong>
— 將工作細分化，設計成即使利用週末或夜間作業也能進行的流程。
</li>
</ol>
<blockquote>
<p>
<span>
<p>
<strong>
Must-Know
</strong>
如果目標模糊，預算與時程都會動搖。透過區分「需求 (Need)」與「想要 (Want)」來建立決策標準。
</p>
</span>
</p>
</blockquote>

<h2>
3. 現狀評估
</h2>
<h3>
3.1 屋頂（瓦片與頂樓防水）
</h3>
<ul>
<li>
確認瓦片下方的防水層狀態 → 標示受損部位。
</li>
<li>
計算頂樓聚氨酯 (Urethane) / 聚脲 (Polyurea) 塗層所需面積。
</li>
</ul>
<h3>
3.2 外牆
</h3>
<ul>
<li>
使用熱成像儀（租用）檢測結露與漏水點。
</li>
<li>
記錄隔熱材厚度與現有飾面層厚度。
</li>
</ul>
<h3>
3.3 內部
</h3>
<ul>
<li>
電線 — 檢查是否有外露或外皮龜裂。
</li>
<li>
給排水 — 記錄主管道直徑與逆流痕跡。
</li>
</ul>
<p>
將照片、尺寸與筆記儲存至
<strong>
Google Drive › Renovation › Survey
</strong>
資料夾。
</p>
<hr>
<h2>
4. 法規與結構限制
</h2>
<ol>
<li>
<strong>
土地分區 / 建蔽率
</strong>
：前往區公所建築科查閱文件。
</li>
<li>
<strong>
識別承重牆
</strong>
：標示木結構桁架與樑的位置。
</li>
<li>
<strong>
頂樓防水許可
</strong>
：妥善保存防水層性能證明書（供保固使用）。
</li>
</ol>

<h2>
6. 預算與時程框架
</h2>
<ul>
<li>
<strong>
預算分配
</strong>
：結構與防水 40% | 隔熱 25% | 設備 20% | 飾面 15%。
</li>
<li>
<strong>
緩衝時間 (Slack)
</strong>
：確保總工期的 20% 為預備日。
</li>
<li>
<strong>
Google Sheets
</strong>
：製作主甘特圖（利用 Drive 範本）。
</li>
</ul>
