## 이게 왜 중요한가요? (Why It Matters)

우리가 지금까지 써왔던 친숙한 챗봇형 AI들은 비유하면 일종의 '고급 음료 자판기' 같았습니다. 동전을 넣고(질문을 하고) 버튼을 누르면 그에 맞는 음료수(대답)가 툭 떨어집니다. 하지만 음료수 자판기에게 "나를 위해 일주일 치 건강 식단을 짜고, 마트에서 장을 본 다음, 매일 아침 내 체질에 맞게 요리까지 해줘"라고 부탁할 수는 없습니다. 자판기는 단발성 요구에만 응답할 뿐, 장기적인 목표를 향해 스스로 움직이지는 못하기 때문입니다.

클로드 페이블 5는 이런 단순한 자판기나 챗봇의 한계를 훌쩍 넘어섰습니다. 이 모델은 사람이 직접 매달리면 몇 시간, 며칠, 심지어 몇 주에 걸쳐서 끙끙대며 해결해야 할 크고 복잡한 프로젝트를 처음부터 끝까지 혼자서 완수해 내는 '독립적인 지식 노동자(Autonomous knowledge worker)'의 역할을 수행하도록 설계되었습니다 [Prompting Claude Fable 5 - Claude API Docs](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5) [ClaudeFable5 - API Pricing & Benchmarks | OpenRouter](https://openrouter.ai/anthropic/claude-fable-5). 

앤스로픽은 이 모델을 가리켜 **'미토스급(Mythos-class)'** 능력을 갖추었다고 부릅니다 [Anthropic Claude Fable 5 on AWS: Mythos-class capabilities with built-in safeguards now available | Amazon Web Services](https://aws.amazon.com/blogs/aws/anthropic-claude-fable-5-on-aws-mythos-class-capabilities-with-built-in-safeguards-now-available/) [ClaudeFable5 - API Pricing & Benchmarks | OpenRouter](https://openrouter.ai/anthropic/claude-fable-5). '미토스(Mythos)'란 신화나 전설을 뜻하는 단어인데요, 이 급의 모델은 당신의 가장 야심 차고 긴 시간이 필요한 프로젝트(Long-running projects)를 위해 만들어졌습니다. 과거의 AI 모델들로는 엄두도 내지 못했던, 복잡하고 모호하며 방대한 문제를 해결하는 데 특화되어 있다는 뜻입니다 [Claude Fable \ Anthropic](https://www.anthropic.com/claude/fable) [Prompting Claude Fable 5 - Claude API Docs](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5). 

이것이 평범한 직장인이나 대중에게 의미하는 바는 엄청납니다. 지금까지는 사용자가 AI에게 일일이 "이 문단을 요약해 줘", "다음엔 이걸 코드로 짜줘"라며 꼬치꼬치 쪼개서 지시해야 했습니다. 인간이 AI의 관리자로서 끊임없이 개입해야만 했죠. 하지만 이제는 "이러한 거대한 목표를 달성해라"라는 큰 방향성만 던져주면 됩니다. 그러면 AI가 알아서 세부 계획을 세우고, 장애물을 만나면 우회하며, 끝까지 책임지고 실행하는 진정한 의미의 '위임'이 가능한 시대가 활짝 열리고 있는 것입니다. 쉽게 말해서, 내 일을 돕는 단순한 '도구'에서 내 일을 스스로 대신해 주는 든든한 '동료'로 진화한 것입니다.

## 쉽게 이해하기 (The Explainer)

그렇다면 클로드 페이블 5는 어떻게 이런 며칠짜리 프로젝트를 혼자 해낼 수 있을까요? 이 모델을 특별하게 만드는 핵심적인 세 가지 특징을 살펴보겠습니다.

**1. 스스로 정답을 맞혀보는 꼼꼼한 모범생: '주도적 자기 검증'**

기존의 AI에게 어려운 수학 문제나 코딩 문제를 던져주면, 오답이든 정답이든 일단 빠르게 문장을 만들어내고 끝을 냈습니다. 오답을 제출하고도 당당하게 서 있는 학생 같았죠. 하지만 클로드 페이블 5는 시험지를 제출하기 전에 철저하게 '검산'을 하는 학생입니다. 

앤스로픽에 따르면, 이 모델은 일하는 방식이 매우 철저(thorough)하고 주도적(proactive)이며, 자신이 만든 결과물을 스스로 테스트합니다 [Claude Fable \ Anthropic](https://www.anthropic.com/claude/fable). 기술적인 용어로는 이를 **'주도적 자기 검증(Proactive self-verification)'**이라고 부릅니다. 이 AI는 작업 도중에 새롭게 배운 내용이 있다면 자신의 기술을 스스로 업데이트하고, 자신의 결과물을 평가하기 위한 자체적인 평가 도구 모음(Evaluations and harnesses)까지 스스로 개발해 냅니다 [Anthropic Claude Fable 5 on AWS: Mythos-class capabilities with built-in safeguards now available | Amazon Web Services](https://aws.amazon.com/blogs/aws/anthropic-claude-fable-5-on-aws-mythos-class-capabilities-with-built-in-safeguards-now-available/). 남이 검사해주기 전에 스스로를 가혹하게 평가하여 완성도를 극도로 높이는 것입니다.

**2. 눈이 달린 코딩 마법사: '시각을 활용한 비판적 검토'**

가장 놀라운 발전 중 하나는 이 AI가 단순히 글자(코드)만 타이핑하는 맹인 마법사가 아니라, 자신이 만든 결과물을 두 눈으로 직접 '본다'는 것입니다. 

예를 들어, 페이블 5에게 컴퓨터 프로그램의 웹 화면을 만들어 달라고 지시했다고 상상해 보세요. 페이블 5는 코드를 작성하여 높은 정확도(High fidelity)로 디자인을 구현해 냅니다. 놀라운 것은 그다음입니다. 자신이 짠 코드의 결과 화면을 시각(Vision, 이미지를 보고 이해하는 기능) 기능으로 직접 확인한 뒤, 애초에 설정했던 목표와 비교하여 비판적으로 평가(Critique)합니다 [Anthropic Claude Fable 5 on AWS: Mythos-class capabilities with built-in safeguards now available | Amazon Web Services](https://aws.amazon.com/blogs/aws/anthropic-claude-fable-5-on-aws-mythos-class-capabilities-with-built-in-safeguards-now-available/). 마치 요리사가 레시피대로 요리를 마친 뒤, 손님 테이블에 내보내기 전에 직접 눈으로 플레이팅을 확인하고 스스로 맛을 보며 평가하는 것과 완벽히 일치합니다. 코딩, 다중 모달(텍스트와 이미지를 동시에 이해하는 능력) 추론 등에서 엄청난 강점을 지니고 있습니다 [AffordableClaudeFable5 API for Coding and Mythos-Class... | Kie.ai](https://kie.ai/claude-fable-5).

**3. 무조건 "네"라고 하지 않는 당돌한 동료: '프롬프트 논평'**

이전의 AI들은 사용자가 아무리 어리석은 질문을 해도 무조건 기계적으로 그럴싸한 대답을 지어내려 했습니다. 하지만 클로드 페이블 5를 써본 사람들은 이 모델이 사용자의 질문(프롬프트) 자체에 대해 스스로 의견을 말하는 듯한 묘한 성향을 즉각적으로 발견하게 됩니다 [Claude Fable 5 is Mythos for the masses - Techzine Global](https://www.techzine.eu/blogs/applications/141978/claude-fable-5-is-mythos-for-the-masses/).

여전히 거대 언어 모델(LLM, 대규모 텍스트 데이터를 학습한 AI)의 틀 안에 있기는 하지만, 페이블 5는 입력된 지시사항에 대해 자기 반성(Self-reflect)을 하는 모습을 보입니다 [Claude Fable 5 is Mythos for the masses - Techzine Global](https://www.techzine.eu/blogs/applications/141978/claude-fable-5-is-mythos-for-the-masses/). "이 질문은 이런 방식으로 접근하는 것이 더 나을 수 있습니다"라며 사용자에게 역으로 피드백을 주는 똑똑하고 당돌한 실무자에 가깝습니다. 잘못된 지시를 내리면 무조건 복종하는 대신 더 나은 길을 제시해 주는 든든한 파트너가 생긴 셈입니다.

## 현재 상황 (Where We Stand)
